📚 Makhanani LTSM — Start Guide for Principals

Learner & Textbook Management • v1.87 • 1 Subject per Learner • 3x5 A4 Stickers • A4 Slip

GIVE THIS PAGE TO EVERY PRINCIPAL

1️⃣ LOGIN — Do This First (2 Minutes)

Step 1: Open your school link (e.g. makhanani-ltsm.web.app) → STEP 1: Search your school by EMIS / Name / Town → Click Select
Step 2: Type Email + Password given to you → Click Login
Forgot Password? Type email → Click Forgot Password? → Check email → Reset.

⚠️ IMPORTANT: Always select the correct EMIS first. If you select the wrong school, you will see another school's books. If login says “This account is NOT for...” — you selected the wrong EMIS. Click Switch School and select again.

2️⃣ ADD STAFF — Admin Page

Go to ⚙️ Admin → Fill Name + Email + Role + Temp Password (e.g. Temp1234) → Save Staff
Roles: PRINCIPAL = You, LIBRARIAN = Library, TEACHER = Teachers.
Tell new staff: Login with that email + temp password, then use Forgot Password to set their own password.

3️⃣ ADD LEARNERS — Learners Page

Go to 🎓 Learners → Type Name + Grade + Class (e.g. 10A) → Add Learner
Barcode auto: LRN-G10-0001
Bulk: Paste 30 names (1 per line) → Grade + Class → Add All Names → Done in 1 click.

4️⃣ ADD BOOKS — Textbooks Page

Go to 📖 Textbooks → Type Title + Subject + Grade + Qty → Add Book(s)
Barcode auto: BK-ACC-G10-0001
Example: Qty 30 = Creates 0001 → 0030 automatically.

5️⃣ PRINT STICKERS — 3x5 A4

On Learners / Textbooks page → Click 🏷️ Print Stickers 3x5 A4
Print: A4 • Margins Default • Scale 100% • Background ON
Result: 3 across × 5 down = 15 stickers per page
✂️ Cut and stick: Books → Inside front cover. Learners → On learner card.

6️⃣ ISSUE / RETURN — Daily Work (Librarian / Teacher)

ISSUE: Go to 📚 Issue / Return → Scan Learner Barcode (LRN-...) + Book Barcode (BK-...) → Pick Due Date → ISSUE BOOK → Click 🖨️ Print Slip → Give slip to learner.
RETURN: Same page → Return section → Scan Book Barcode only → Pick Condition (Good / Damaged / Lost) → RETURN BOOK → Print Return Slip.

✅ RULE — 1 Subject per Learner: If learner already has Accounting OUT, system will BLOCK a 2nd Accounting book. They must return the first one, or take a different subject. This is automatic — you don't need to check.

7️⃣ DAMAGED / LOST — Librarian Page

Go to 📚 Librarian → Damaged / Lost section → Scan Book Barcode → Choose DAMAGED or LOST → Mark. To fix a repaired book → Choose Good → Mark Good. Damaged books will NOT be issued again until fixed.

8️⃣ PRINCIPAL DAILY CHECK — 1 Minute

Go to 🏠 Home → See: Books OUT / Overdue / Available / Issued Today → Go to 👩🏾‍🏫 Principal → See Overdue Report + Approve Pending Staff + Subscription. If subscription shows EXPIRED / PENDING — contact Makhanani to renew, or your school will be blocked.

❌ DO NOT: Do not delete a learner / book that is OUT — return it first. Do not share your password. Do not use another school's EMIS. Do not delete staff — ask Makhanani if unsure.
