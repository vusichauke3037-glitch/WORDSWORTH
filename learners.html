⚡ Quick Rules — Learners — Dropdowns Required

  • Grade ▼ + Class ▼ are REQUIRED. Add button is DISABLED until you pick both. Dropdown turns GREEN ✅ when picked.
  • Learner ID = Grade + Class + 3 Digits. Grade 10 Class A = 10A001, Grade 8 Class B = 8B001.
  • 1 learner = 1 ID. Never give 2 learners same ID.
  • Next ID is per class: If last in 10A is 10A015, new in 10A is 10A016. 10B starts again at 10B001.
  • Bulk: Pick Grade + Class in dropdowns FIRST → Paste names → All get that Grade/Class.
