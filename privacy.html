4. Why We Use It — Purpose (POPIA Section 13)

We use personal information ONLY for these purposes:

  1. To run Makhanani: Login, Issue / Return, % Retrieval, Stock, Barcodes, Reports.
  2. To manage subscriptions: Know if school is DEMO / Paid / Expired / Blocked, Send renewal reminders.
  3. To support you: Reply to WhatsApp, Fix bugs, Reset passwords (via Principal), Train staff.
  4. To keep system secure: Stop hacking, Stop one school seeing another school's data, Block abuse.
  5. To improve Makhanani: Count how many books issued (anonymous), Fix slow pages, Add features schools ask for.
  6. To follow law: If court / police ask for data by law, we must follow law (see Section 9).

We do NOT use personal information for: Selling to advertisers, Marketing to learners, Marketing to parents (except Makhanani messages to that school's Principal / Librarian), Profiling learners, Credit checks.

6. Where Data Is Stored — Cross-Border (POPIA Section 72)

Data is stored in Firebase (Google Cloud). Google data centres may be outside South Africa (e.g. USA, Europe).

By using Makhanani, School agrees that data may be stored outside South Africa. Google protects data with encryption + access controls, as in Google's Privacy Policy and Firebase Terms.

If School does NOT want data outside South Africa, do not use Makhanani. There is no South-Africa-only storage option in current version.

7. How We Protect Data — Security (POPIA Section 19)

  • Passwords: Passwords are stored in Firebase. Never share passwords. Change password if you think someone knows it.
  • Separate Schools: Each school has its own Firestore / RTDB path (schools/[schoolId]/...). One school cannot see another school's path.
  • Role Checks: System checks Role on login. Teacher cannot open Librarian / Principal pages with Admin data.
  • HTTPS: Makhanani uses HTTPS (encrypted) when you login and save.
  • Access: Only Vusi + Firebase Admins can access Firebase Console. No other person has access unless Vusi gives it.
  • Devices: School must keep phones / computers locked. If phone is stolen, tell Principal to change password immediately.
No system is 100% secure. If we find a data breach (someone accessed data they should not), we will tell affected Principals by WhatsApp / Email within 48 hours of finding it, and tell Information Regulator if POPIA requires, as in Section 10.

9. When We Must Share Data By Law

We will only share personal information by law if:

  • Court order, subpoena, or police request under South African law requires it.
  • Information Regulator asks for it under POPIA.
  • It is needed to prevent serious harm (e.g. child safety).

If we must share, we will tell Principal first, unless law says we cannot tell (e.g. police investigation).

10. Data Breach — What We Do

  1. If we find a breach, we will secure system (change passwords, block access).
  2. We will tell affected Principals by WhatsApp / Email within 48 hours — What happened, What data was affected, What we did, What you should do.
  3. We will tell Information Regulator (South Africa) if POPIA requires, within time POPIA requires.
  4. We will fix breach and tell Principals when fixed.

School must also tell us immediately if they think data was breached (e.g. someone logged in with stolen password, learner data seen by wrong person).

13. Cookies + Tracking

  • Makhanani uses localStorage on your phone / browser to keep you logged in (makhanani_user). This is not a cookie, but works like one.

  • You can clear localStorage by logging out. Logout deletes makhanani_user from your device.
