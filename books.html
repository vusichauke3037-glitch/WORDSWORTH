⚡ Quick Rules — Textbooks

  • Textbook Number = School Initials + 6 Digits. Makhanani Primary School = MPS000001.
  • 1 copy = 1 number. Never give 2 copies same number — System will think it's same textbook.
  • Print: Click 📚 Print Barcode → Opens book_barcode.html with that textbook already filled.
  • Bulk: Use Add Many Copies for 5, 10, 30 copies of same title.
  • Lost label? Same number → Print again. New copy? New number.
  • Stick inside front cover + Cover with clear tape.
