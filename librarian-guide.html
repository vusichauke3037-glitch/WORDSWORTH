📚 Makhanani LTSM — Guide for Librarians / Teachers

Your Daily Job: Issue • Return • Damaged / Lost • Print Slip • v1.87

KEEP THIS PAGE AT THE LIBRARY DESK

1️⃣ LOGIN — Every Morning

Step 1: Open makhanani-ltsm.web.app → STEP 1: Search your school by EMIS / Name / Town → Click Select → STEP 2: Type Email + Password → Login
Forgot Password? Type email → Forgot Password? → Check email → Reset. Do NOT use another school's EMIS.

2️⃣ ISSUE A BOOK — Learner Comes With Card + Book

Go to: 📚 Librarian (or 📚 Issue / Return — both work the same)

1. Scan / Type Learner Barcode — on learner card: LRN-G10-0001
2. Scan / Type Book Barcode — inside book cover: BK-ACC-G10-0001
3. Check Due Date — usually 14 days from today. Change if Principal says different.
4. Click ✅ ISSUE BOOK → Slip appears → Click 🖨️ Print Slip → Give slip to learner → Learner signs.
5. Click 🧹 Clear → Next learner.

Tip: You can type the barcode with keyboard if scanner is not working. Always check learner name + book title on screen before clicking ISSUE.

✅ RULE — 1 Subject per Learner (Automatic): If learner already has Accounting OUT, system will BLOCK a 2nd Accounting book: ❌ BLOCKED: 1 Subject per Learner. Tell learner: “Return your first Accounting book first, or take a different subject.” You do NOT need to remember — system checks it.

3️⃣ RETURN A BOOK

1. Same page → 📥 Return Book section
2. Scan / Type Book Barcode ONLY — BK-...
3. Pick Condition: Good / Fair / Damaged / Lost
4. Click 📥 RETURN BOOK → Print Return Slip if needed.
Result: Book becomes Available again. Learner can now take another book of same subject.

4️⃣ IF IT SAYS BLOCKED / NOT FOUND

❌ Book already OUT: Book is with another learner. Check who has it in Search → Ask them to return it.
❌ Learner NOT FOUND: Wrong EMIS selected OR learner not added. Ask Principal to add learner.
❌ Book NOT FOUND: Wrong EMIS OR book not added. Ask Principal to add book.
⚠️ Grade mismatch: Learner is Grade 10 but book is Grade 11 — Check if correct, continue only if Principal says yes.

5️⃣ DAMAGED / LOST — What To Do

On Return: If book is torn / wet / pages missing → On Return, pick Damaged → Book goes to Damaged List and will NOT be issued again.
On Shelf: If you find a damaged book on shelf → Go to ⚠️ Damaged / Lost section → Scan BK-... → Choose DAMAGED or LOST → Add note (e.g. “Torn pages”) → MARK.
Fixed? If book is repaired → Scan it → Choose Good → MARK GOOD → Book becomes Available again.
Lost? Mark as LOST → Tell Principal → Principal decides if learner must pay / replace.

6️⃣ PRINTING — Stickers & Slips

Slip: After Issue / Return → Click 🖨️ Print Slip → Print: A4 • Margins Default • Scale 100% → Only the slip prints, 1 page. Get signatures: Learner + Librarian.
Stickers (if Principal asks you): Go to 🎓 Learners or 📖 Textbooks → 🏷️ Print Stickers 3x5 A4 → Prints 15 per page (3 across × 5 down). Cut and stick.

📋 END OF DAY CHECKLIST (2 Minutes): 1) Go to 🏠 Home → Check Books OUT / Overdue → 2) If Overdue list is long, tell Principal → 3) Check Damaged List → Tell Principal if books need replacing → 4) Log out → Close browser.
❌ DO NOT: Do not delete learners or books. Do not give your password to learners. Do not issue a book without scanning BOTH barcodes. Do not mark a book Damaged / Lost unless you checked it. If unsure — ask Principal, do not guess.
