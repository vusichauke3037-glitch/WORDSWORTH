Session 2 — Librarian: Books + Learners + Users (09:30) — Librarian + HOD + Principal

Exercise A — Add Book With Quantity (Most Important)

  1. Librarian → Books → Check Starting Barcode — Auto-filled (e.g. TP000001) — Do NOT change unless you know why.
  2. Title: Mathematics Grade 10 • Subject: MATHEMATICS (dropdown, ALL CAPS) • Grade: 10 • Author: Maskew Miller • Group: FET (or leave)
  3. Quantity: 5 → Check Preview: Will create: 5 copies — TP000001 to TP000005
  4. Click ADD BOOKS → Check: ✅ Added 5 copies
  5. Books List: Check grouped row — Qty: 5, Available: 5, Issued: 0
Common Mistakes:
❌ Adding 1 book at a time for 50 copies (takes 1 hour) — Use Quantity.
❌ Typing subject in lowercase "maths" — Use dropdown MATHEMATICS.
❌ Changing Starting Barcode to 000001 — Use full prefix TP000001.

Exercise B — Add Learner + Bulk Add

  1. Learners → Name: Test Learner • Click AUTO ID → Add → Check ID created (e.g. 10A001)
  2. Bulk Add: Grade 10, Class A, Paste 3 names (1 per line) → BULK ADD → Check IDs 10A001, 10A002, 10A003
  3. Try duplicate ID: Add same ID again → Check: ⛔ BLOCKED — ID already exists
  4. Try duplicate name: Add same name with different ID → Check: ✅ Allowed — Name duplicate is allowed, ID duplicate is not.

Exercise C — Add Teacher (Must Have Subject)

  1. Users → Name + Email + Password + Role TEACHER → NO Subject → Try Save → Check: ⛔ BLOCKED — Must have subject
  2. Pick Subject 1: MATHEMATICS → Save → Check: ✅ Saved
  3. Reset password: Click 🔑 Reset 1234 → Check password becomes 1234
  4. Try to add Teacher with same email as existing → Check: ⛔ BLOCKED — Email already exists
☐ Added book with Quantity   ☐ Bulk added learners   ☐ Added teacher with subject   ☐ Saw duplicate ID blocked   ☐ Saw teacher-no-subject blocked

Session 3 — Issue / Return — Camera Scan (11:00) — All

Exercise D — Issue (10 Seconds)

  1. Issue → Pick Learner (from Exercise B) → Scan Book (from Exercise A) — Camera or type barcode → ISSUE
  2. Check: Due Date = 30 November (automatic, not today + 14 days)
  3. WhatsApp parent: Click Yes → WhatsApp opens with "Your child was issued [Title] — Due 30 November" → Send
  4. Check Learner row: Now shows Issued: 1

Exercise E — Blocked Cases (Try All 3 — This Is The Test)

  1. One Learner One Title: Issue same Title again to same learner → Check: ⛔ BLOCKED — Learner already has this Title
    Why? Learner cannot take 2 copies of same Title. Return first, then issue again.
  2. Grade Mismatch: Grade 10 learner + Grade 11 book → Check: ⛔ BLOCKED — Grade mismatch
    Why? Learner must get books for their Grade only.
  3. Teacher Own Subject: Teacher (MATHS) + ENGLISH book → Check: ⛔ BLOCKED — Teacher can only issue own subject
    Why? Teacher = Own Subject Only. Librarian can issue any subject.

Exercise F — Return (5 Seconds)

  1. Return → Scan same barcode → RETURN → Check: Book becomes AVAILABLE
  2. Try return by Teacher of other subject → Check: ✅ Allowed (Return = Any Book — Anyone can return)
  3. Try return same barcode again → Check: ⛔ Already returned / Not issued
☐ Issued book   ☐ Saw 3 blocked cases   ☐ Returned book   ☐ WhatsApp parent worked   ☐ Know Due Date = 30 Nov

  • Login as Teacher → Check: See only my class (e.g. 10A, not 10B, not whole school)
  • Issue my subject (MATHS) → ✅ Allowed

  • Return any book → ✅ Allowed
  • Try to open Librarian → Add buttons disabled → ⛔ Teachers cannot add/edit books, learners, users
  • Try to see other class's learners → ⛔ Not visible

Session 5 — Stock + Barcodes + Stock Take (12:30) — Librarian + HOD

Exercise H — Barcodes

  1. Barcode → Filter to Title from Exercise A → Print → Check: 15 barcodes per A4, 3×5, Title + Barcode + School Name
  2. Cut 1 barcode, stick on book, scan it in Issue → Check: Finds book
  3. Check: If you print 2 pages for 20 copies, first page 15, second page 5

Exercise I — Stock Take (End Of Term)

  1. Stock → Stock Take → Filter to Grade 10 / MATHEMATICS → START CAMERA SCAN → Scan 5 books on shelf → FINISH
  2. Check: Found 5, Missing shows rest (not scanned = missing or issued)
  3. Check: If you scan same barcode twice, it counts once

Exercise J — Lost / Damaged

  1. Stock → Lost / Damaged → Scan 1 barcode → Reason LOST → Learner + Charge R150 → MARK LOST
  2. Check: Book removed from Available, % Lost goes up, Learner shows Lost
  3. Restore it: Click ✅ Restore → Check: Book back to Available
Lost vs Damaged: LOST = Learner lost book, charge parent. DAMAGED = Book torn / wet, charge or not — Principal decides. Both remove book from Available until restored.
☐ Printed barcodes   ☐ Did Stock Take   ☐ Marked Lost + Restored

Session 6 — Principal: % Retrieval + Reports (13:15) — Principal + HOD

Exercise K — Read % Retrieval

  1. Principal → Dashboard → Top: % Retrieval + % Outstanding (big gold boxes)
  2. By Class tab: Find lowest class — Who is behind?
  3. By Group tab: Find lowest Group / Subject
  4. Teachers tab: Find lowest teacher % Retrieval
% Retrieval = Returned ÷ Issued × 100
Example: Issued 50, Returned 42 → 84% Retrieval, 16% Outstanding
Green ≥90% • Orange 70–89% • Red <70% • Target 100% by 30 November

How to talk in staff meeting:
"10A is 96%, 10B is 75% — 10B, chase your learners. MATHEMATICS is 88%, ENGLISH is 65% — ENGLISH, what is happening?" — No argument, number is there.

Exercise L — Send Report

  1. Report tab → Phone: 0780233263 (or your own) → SEND WHATSAPP REPORT (Filtered) → Check WhatsApp opens with % Retrieval
  2. PRINT REPORT → Check print shows % per Group / Subject / Class
  3. Check: Report shows Issued, Returned, Still Out, % Retrieval
☐ Read % Retrieval   ☐ Sent WhatsApp Report   ☐ Printed Report   ☐ Can explain % Retrieval to SGB
