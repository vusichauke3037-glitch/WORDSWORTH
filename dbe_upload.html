📤 Upload CSV — Format: EMIS,NAME,TOWN,PROVINCE

FORMAT — 4 COLUMNS ONLY — IN THIS ORDER:
EMIS,NAME,TOWN,PROVINCE
123456789,THUTO PRIMARY,Alexandra,GAUTENG

  • EMIS: DBE EMIS number — Unique. If EMIS already exists, it will SKIP.
  • NAME: School Name — e.g. THUTO PRIMARY. Saved in CAPS.
  • TOWN: Town / Area — e.g. Alexandra, Polokwane, Soweto, Tembisa. This is Town, not District.
  • PROVINCE: GAUTENG / LIMPOPO / MPUMALANGA / KZN / etc. Use CAPS.
  • First row = Header: Must be EMIS,NAME,TOWN,PROVINCE — System will skip header automatically.
  • Max per upload: 500 schools at a time.
  • Old 12-column files still work: Auto-detects old format too.
