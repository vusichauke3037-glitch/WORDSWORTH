🛠️ 8. When School Is In Return Only — What To Do

WhoDo This
Librarian / Teacher1. Keep RETURNING books — do not stop returns.
2. Tell Principal: “School is in Return Only — contact Xintimani Group.”
3. Do NOT try to bypass — Issue / Add is blocked on purpose.
Principal1. Check principal.html → My School Subscription → See End Date / Plan.
2. Check pricing in Principal page (Principal sees pricing) → Decide plan.
3. Contact Xintimani Group — pay / renew.
4. Ask Admin to reactivate in Admin → All Schools.
Admin / Xintimani Group1. Login as ADMIN → admin.html → All Schools.
2. Find school → Tap ✅ Activate OR 📅 +12 Months to extend + reactivate.
3. Tell school to logout → login again → Check ISSUE works.
⚠️ Never delete a school to “fix” subscription. Delete only removes school doc, not learners / books. Use ✅ Activate or 📅 +12 Months instead.
