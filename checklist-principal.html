🤖 2. Auto-Generate IDs — You Don't Type Codes

🤖 No more typing codes by hand. System auto-generates next free ID / Number. It never gives a duplicate. You can still type your own if school already has old IDs — untick 🤖 Auto.
TypeFormatExamplesHow It Works

Grade 10, Class 10B → 10B001
Grade 11, Class 11A → 11A001		Pick Grade + Class → ID auto-fills
