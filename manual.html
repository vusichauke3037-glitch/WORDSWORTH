3. 📦 Stock — Organised By Department → Grade → Subject

New in V3.4 — Stock is NOT one long list anymore. It is grouped.

LevelExample — Wordsworth
🏢 Department / GroupMathematics & Sciences • Languages • Commerce & EMS • Humanities • Creative & Technical • Foundation Phase
🎓 GradeGrade 10 • Grade 11 • Grade 12
📖 SubjectMathematics • Physical Sciences • Life Sciences
📚 BookMathematics Grade 10 — WHS000001 — Qty 10
Add Book:
  1. Go to 📦 STOCK
  2. Pick Department → Subject list auto-changes. E.g. Mathematics & Sciences → Maths, Physical Sciences, Life Sciences
  3. Pick Grade → e.g. Grade 10
  4. Pick Subject → e.g. Mathematics
  5. Type Title → e.g. Mathematics Grade 10, Author DBE, Qty 10
  6. Click 🎲 AUTO — NEXT BOOK NUMBER → WHS000001
  7. Click ✅ ADD TO STOCK → Book goes straight into correct group
Find Book: Filter Department → Grade → Subject at top → Only those books show. Or type title / barcode in search. Toggle 📂 Group (grouped) / 📋 List (flat list with Dept / Grade / Subject columns).
⚠️ Fix Old Books: Old books have no Department. Click 🏢 Dept next to any old book → Type Department / Subject / Grade → Save → It moves to correct group.

HOD View: HOD for Maths filters Department = Mathematics & Sciences — they don't see Languages clutter. Low Stock: Qty < 5 shows ⚠️ LOW STOCK.

4. 🎓 Learners — Organised By Grade → Class → Stream

LevelExample — Wordsworth
🎓 GradeGrade 10 • Grade 11 • Grade 12
🏫 Class10A • 10B • 10C
📚 Stream / GroupScience • Commerce • Humanities • General • Foundation Phase (R-7)
👤 LearnerThabo Mokoena — 10A001
Add Learner:
  1. Go to 🎓 LEARNERS
  2. Pick Grade → Stream list auto-changes. Grade 10-12 = Science / Commerce / Humanities. Grade R-7 = Foundation Phase
  3. Pick Class → e.g. A, Stream → e.g. Science
  4. Click 🎲 AUTO — NEXT LEARNER ID → 10A001
  5. Click ✅ ADD LEARNER
Bulk Class: Set Grade + Class + Stream → Paste 30 names (one per line) → 👥 ADD ALL + AUTO IDs → 10A001 to 10A030, all same Stream.
Find Learner: Filter Grade → Class → Stream → Only that group shows. Perfect for printing cards for one stream only. Toggle 📂 Group / 📋 List.
⚠️ Fix Old Learners: Old learners have no Stream. Click 📚 Stream → Type Stream / Grade / Class → Save → Moves to correct group.

6. 🖨️ Print Barcodes — A4 3x5 — 15 Per Page

For Books: 🖨️ PRINT BARCODES → Type = 📚 BOOK → School = Wordsworth → Subject = Mathematics, Grade 10 → Start 1 → WHS000001 → How Many 15 → 👁️ PREVIEW → 🖨️ PRINT A4 NOW
For Learners — Whole Class: Type = 🎓 LEARNER, Grade 10, Class A → Paste class list in Batch → 👥 GENERATE BATCH → 10A001, 10A002... → 🖨️ PRINT A4 NOW
🖨️ Print Settings: Paper A4 • Margins None • Scale 100% • Background Graphics ON • Laser printer + sticker paper. Stick book barcode on book cover (front, bottom corner). Give learner card to learner.
💾 Save To Firebase: In Print page, click 💾 SAVE TO FIREBASE — adds printed books to Stock so Issue scan will find them.

7. ⚡ Double Scan — Issue In 2 Seconds + Grade / Stream Filter

New in V3.4 — Issue filters books by learner's Grade / Stream.

STEP 1 — Scan Learner: Issue → 📷 SCAN LEARNER CARD → → Point at card (10A001) → Shows Grade 10 • Class 10A • Stream: Science → Book list auto-filters to Science subjects only (Maths, Physics, Life Sciences, English...)
STEP 2 — Scan Book: Issue → 📷 SCAN BOOK BARCODE → → Point at book (WHS000001) → Shows Maths & Sciences → Grade 10 → Mathematics → If book Grade ≠ learner Grade, shows ⚠️ GRADE MISMATCH warning
STEP 3 — Issue: Button turns green: ✅ ISSUE OUT NOW — Mathematics → Thabo → Tap it → Stock auto 10 → 9. Form resets.
Learner StreamBooks They See
ScienceMaths, Physical Sciences, Life Sciences, English, Life Orientation
CommerceAccounting, Business Studies, Economics, Maths, English
HumanitiesGeography, History, Life Orientation, English
✅ Queue: Scan learner, scan book, Issue, next learner. 1 learner = ~5 sec. 30 learners = ~3 min.

No Camera? Pick Grade + Stream in Manual Filter → Book list filters → Type Learner ID (10A001) + Book Number (WHS000001) → Press Enter → Same auto-fill.

8. 🔙 Return Books

  1. Issue page → Same Double Scan: Scan Learner + Scan Book
  2. Change Action to RETURN
  3. Click ✅ SAVE ISSUE / RETURN → Stock auto 9 → 10
  4. OR in Recent Issues → Click 📥 Return
⚠️ Always scan Return — do NOT just put book back on shelf. If you don't scan Return, system still thinks learner has the book.

9. 👔 HOD — Approve Teacher Requests

  1. Teacher: 👩‍🏫 TEACHER → Request Book From HOD → Fill Book + Learner / Class → Send
  2. HOD: 👔 HOD → See ⏳ Pending
  3. Check 📦 STOCK → Filter to your Department → Is book in stock?
  4. If YES → ✅ Approve → Librarian can issue. If NO → ❌ Reject

10. 🏫 Principal / School Admin — Reports

  1. Go to 🏫 PRINCIPAL or 🏫 SCHOOL ADMIN
  2. See: Total Books, Issued Out, Returned, Low Stock, Learners, Users
  3. Check Low Stock → Order more books — Filter by Department to see which Department is low
  4. Check Issues → Filter by Grade / Stream → Who has books out longest

11. 🛠️ Problems — Quick Fix

ProblemFix

Barcode won't scanPrint again — Scale 100%, Background ON, not blurry. Hold 15cm away, good light.
Scanned code says "Not Found"Book / Learner not in Stock / Learners yet. Add it first, then print, then scan.
Wrong school / Blank schoolHome → ✅ SET MY SCHOOL TO WORDSWORTH
Can't add stock / Teacher blockedTeacher cannot add stock. Ask SCHOOL_ADMIN to change Role to LIBRARIAN / HOD.
Book in wrong groupStock → Click 🏢 Dept → Fix Department / Subject / Grade. Learners → Click 📚 Stream → Fix Stream / Grade / Class.
Grade Mismatch warningCheck you scanned correct book. If learner is advanced, you can still issue — warning is just a check.
Stock didn't go -1 after IssueBook title must match Stock exactly. Use Scan — it matches automatically.
Print too small / Cut offPrint Settings: A4, Margins None, Scale 100%, Background ON.

12. ✅ Daily Checklist — Librarian

🌅 Morning
  • Open App → Login
  • Check Stock → Filter by Department → Any Low Stock?
  • Check Pending Issues
📚 During Day
  • Double Scan: Learner + Book → Issue
  • Keep queue moving — 5 sec per learner
🔙 End Of Day
  • Double Scan Returns → Stock +1
  • Count shelf vs System Qty per Subject
🖨️ Weekly
  • Print barcodes for new books (by Subject)
  • Print cards for new learners (by Class / Stream)
  • Report Low Stock to HOD / Principal
✅ Golden Rule: Every book that leaves MUST be scanned. Every book that comes back MUST be scanned. No scan = Lost book.
