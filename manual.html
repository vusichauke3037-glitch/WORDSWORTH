1. Quick Start — First Day In 10 Minutes

Do these in order. Do not skip Step 1.
Step 1 — Login as Principal / Librarian
Open index.html → Log in with the Principal account given by Vusi.
Step 2 — Add Teachers
Principal → Teachers tab → Add each teacher → Name + Email + Password + Subject 1 (Required) + Class. Teacher cannot log in without a subject.
Step 3 — Add Learners
Librarian → Learners → Bulk Add → Paste names, one per line → Auto IDs. Example: Grade 10, Class A → IDs become 10A001, 10A002...
Step 4 — Add Books
Librarian → Books → Scan barcode OR type → Title + Subject (dropdown) + Grade. Barcode auto-creates: THUTO PRIMARY → TP000001, TP000002...
Step 5 — Print Barcodes
Barcode page → Pick books → Print A4 → Cut → Stick on books.
Step 6 — Issue Books
Issue page → Pick Learner → Scan Book → ISSUE → WhatsApp parent. All books due 30 November.
Step 7 — End Of Year — Stock Take
Stock → Stock Take → Scan every book on shelf → FINISH → Shows Missing. Learners return books by 30 November.

3. Rules — Read This First (All Users)

RuleWhat Happens
1. All books due 30 November every yearEvery book issued this year is due 30 November. Due date is locked, cannot be changed. If you issue on 1 Dec, due is 30 Nov next year. Use Fix All Due Dates To 30 Nov in Principal / Issue to fix old books.
2. One Learner = One TitleLearner cannot have 2 copies of same Title. Example: Thandi has Mathematics Grade 10 — Cannot issue another Mathematics Grade 10 until she returns first one. System blocks with ⛔.
3. Grade Must MatchGrade 10 learner = Grade 10 book only. Grade 10 learner cannot take Grade 11 book. System blocks with ⛔ Grade Mismatch.
4. Teacher = Own Subject OnlyTeacher who teaches MATHEMATICS can only issue MATHEMATICS books. Teacher cannot issue ENGLISH books. Librarian / HOD / Principal / Admin can issue any subject.
5. Return = Any BookAnyone can return any book. Teacher can return ENGLISH book even if they teach MATHEMATICS. No grade / subject check on return.
6. Name Duplicate AllowedTwo learners can have same name. Example: Two Thandi Mokoena can exist — One 10A001, one 10A002. Do NOT delete one thinking it is duplicate.
7. Learner ID Duplicate BlockedTwo learners CANNOT have same Learner ID. 10A001 belongs to one learner only. System blocks and shows who has that ID. Use AUTO ID to avoid this.
8. Teacher Must Have At Least 1 SubjectCannot save a Teacher without a Teaching Subject. Subject 1 is required. Subject 2 is optional (for teachers who teach 2 subjects).
9. Subjects From Dropdown — ALL CAPSSubjects are picked from dropdown, not typed. All subjects are in ALL CAPS: MATHEMATICS, ENGLISH HOME LANGUAGE, PHYSICAL SCIENCES, etc. This stops spelling mistakes.
10. Stock Organized By Group → Grade → SubjectEvery book has Group / Department + Grade + Subject + Title. Example: MATHEMATICS & SCIENCES → Grade 10 → MATHEMATICS → Mathematics Grade 10.

5. Librarian — Add Books, Learners, Users

5A. Add A Book

  1. Go to Librarian → Books.
  2. Barcode: Scan with camera OR type. Next barcode is auto-filled. Example: TP000001.
  3. Title: Type book title. Example: Mathematics Grade 10.
  4. Subject: Pick from dropdown — Do not type. Example: MATHEMATICS.
  5. Grade: Pick Grade. Example: 10.
  6. Group / Department: Leave Auto, or pick. Example: MATHEMATICS & SCIENCES.
  7. Author: Type author. Example: Maskew Miller.
  8. Click ADD / UPDATE BOOK.
Book No format: First letter of each word of school name + 6 digits. THUTO PRIMARY → TP + 000001 = TP000001. Next book auto becomes TP000002.

5B. Add A Learner — One By One

  1. Librarian → Learners → Name + Learner ID + Grade + Class + Parent Phone.
  2. Click AUTO Learner ID to avoid duplicate ID errors.
  3. Click ADD / UPDATE LEARNER.
  4. If ID already exists, system blocks: ⛔ ID 10A001 already belongs to Thandi Mokoena — Use a different ID.
  5. Same name is allowed — Do not worry if two learners have same name.

5C. Bulk Add Learners — Whole Class At Once

  1. Librarian → Learners → Bulk Add → Pick Grade (e.g. 10) + Class Letter (e.g. A).
  2. Paste names, one per line:
    Thandi Mokoena
    Sipho Dube
    Zanele Nkosi
  3. Click BULK ADD + AUTO IDs. System creates 10A001, 10A002, 10A003...
  4. Same name twice = Allowed. It will create two learners with different IDs.

5D. Add A User / Teacher

  1. Librarian → Users / Teachers → Name + Email + Password (min 6) + Role.
  2. If Role = TEACHER, Subject 1 is REQUIRED. Pick from dropdown. Without subject, teacher cannot be saved.
  3. Subject 2 is optional — For teachers who teach 2 subjects.
  4. Class: Teacher's class. Example: 10A. Teacher will only see that class.
  5. Click ADD USER.
  6. To reset a teacher who forgot password: Click 🔑 Reset 1234 next to their name.

5E. Scan & Find

  • Librarian → Scan & Find → Click START CAMERA SCAN → Point at barcode.
  • If it is a book: Shows Title, Subject, Grade, and if it is OUT to which learner.
  • If it is a Learner ID: Shows Learner name + Class.
  • If not found: Shows ⚠️ Not found — Check barcode or add book first.

6. Issue / Return — Camera Scan

Issue A Book

  1. Go to Issue / Return → Issue Book.
  2. Learner: Type name or ID → Pick learner from dropdown. Check: Name, Grade, Class, Books Out.
  3. Book: Scan barcode with camera OR type barcode. Check: Title, Subject, Grade.
  4. Due Date: Shows 30 November — Locked, cannot change.
  5. Click ISSUE BOOK.
  6. If blocked, read the red message — It tells you why: One Title, Grade Mismatch, or Teacher Subject.
  7. After issuing, click Yes to WhatsApp parent. Message says: Thandi borrowed Mathematics Grade 10 — Return by 30 November.

Return A Book

  1. Go to Issue / Return → Return Book.
  2. Scan barcode OR type barcode → Click RETURN BOOK.
  3. Or find book in Books Out list → Click 📥 Return next to it.
  4. Anyone can return any book. Teacher can return any subject, any grade.

Camera Scan Tips

  • Allow camera when browser asks.
  • Hold phone 15–20 cm from barcode, steady, good light.
  • If scan fails, type barcode manually and press Enter.
  • Camera stops automatically after 1 scan in Issue. In Stock Take, camera keeps scanning.
Blocked Examples:
⛔ One Learner One Title — Learner already has that Title.
⛔ Grade Mismatch — Learner Grade 10, Book Grade 11.
⛔ Teacher Own Subject Only — You teach MATHEMATICS, this book is ENGLISH.

7. Teacher — My Class Only

  • Teacher sees only their class. Example: Teacher of 10A sees only 10A learners, not 10B.
  • Teacher can issue only their subject. Example: MATHEMATICS teacher can only issue MATHEMATICS books.
  • Teacher can return any book — Any subject, any grade.
  • Teacher cannot add/edit learners, books, or other teachers. No Add buttons in Teacher page.
  • Teacher can WhatsApp parents of their class only for Overdue books.

Teacher Daily Flow

  1. Login → See My Learners (your class).
  2. Issue Book tab → Pick learner in your class → Scan book (your subject) → Issue.
  3. Books Out tab → See who has books out → Click Return when learner brings book back.
  4. Overdue tab → See overdue in your class → WhatsApp parent.

Add Stock — New Books Arrived

  1. Stock → Add Stock → Pick Group + Grade + Subject + Title.
  2. How Many Copies? Example: 10.
  3. Click ADD STOCK. System creates barcodes automatically: TP000101 to TP000110.
  4. Click Print Barcodes For Last Added → Go to Barcode page → Print.

Low Stock

  • Any Title with less than 5 Available shows in Low Stock.
  • Click ➕ Add Stock next to it — Form auto-fills Group + Grade + Subject + Title.

Stock Take — End Of Term / End Of Year

  1. Filter to Group / Grade / Subject you want to count. Example: MATHEMATICS & SCIENCES / Grade 10 / MATHEMATICS.
  2. Stock → Stock Take → START CAMERA SCAN.
  3. Scan every book on shelf, one by one. Camera keeps scanning. Duplicate scans ignored.
  4. Click FINISH STOCK TAKE.
  5. Result shows: Found, Missing (in system, not scanned), Extra (scanned, not in system).
  6. Click Yes to WhatsApp Missing List to Principal.
Tip: Do Stock Take after learners return books by 30 November. That is why all books are due 30 November — So Stock Take is accurate.

Lost / Damaged

  1. Stock → Lost / Damaged → Scan / Type barcode.
  2. Reason: LOST / DAMAGED / STOLEN / WORN OUT.
  3. Learner who lost it + Charge (e.g. R150) + Note.
  4. Click MARK LOST / DAMAGED. Book is removed from Available.
  5. If book is found later: Click ✅ Restore in Lost List.
  6. Click WhatsApp Lost List to send list + total charge to Principal.

9. Barcodes — Print A4 3×5

  1. Go to Barcode page.
  2. Pick books to print: By Group / Grade / Subject, or Last Added, or All.
  3. Click Print. A4 page shows 3 columns × 5 rows = 15 barcodes per page.
  4. Each barcode shows: Title, Barcode number (e.g. TP000001), School name.
  5. Print on sticker paper or normal paper → Cut → Stick on book cover (front inside cover).
  6. Test: Scan printed barcode with Issue page — Should find book.
Do not photocopy barcodes. Each barcode is unique to one copy. Photocopying creates duplicate barcodes and system will think 2 books are 1 book.

10. Principal — Dashboard, Teachers, Reports

Dashboard

  • KPIs at top: Learners, Total Books, Available, Out, Overdue, Lost/Damaged.
  • By Group / Dept tab: Same tree as Stock — Group → Grade → Subject → Title + Green bar % Available.
  • By Class tab: Each class → Learners, Books Out, Overdue, Teacher assigned. If class shows No Teacher Assigned, add teacher with that Class.

Manage Teachers

  1. Principal → Teachers → Add Teacher: Name + Email + Password + Subject 1 (Required) + Subject 2 (Optional) + Class.
  2. Change Class / Subject: Click ✏️ Change Class / Subject next to teacher → Type new Class + Subject.
  3. Reset Password: Click 🔑 Reset 1234 → Teacher logs in with 1234.
  4. Delete: Click Delete — Only if teacher left school.

WhatsApp Report

  1. Principal → WhatsApp Report → Type phone (e.g. 0780233263 for Vusi / SGB / Circuit).
  2. Filter first if you want only one Group / Grade / Subject. Example: Filter to MATHEMATICS & SCIENCES / Grade 10 → Send that report only.
  3. Click SEND WHATSAPP REPORT (Filtered) for filtered report, or SEND FULL SCHOOL REPORT for whole school.
  4. Click PRINT REPORT to print on paper.
  5. Click Fix All Due Dates To 30 Nov if old books have wrong due dates.
Report includes: Total, Available, Out, Overdue, Lost, Learners, Teachers, By Group, By Grade, By Subject, Overdue list, Lost list.

11. Overdue + Lost / Damaged

Overdue

  • Overdue = Book not returned after Due Date (30 November).
  • On 1 December, all books not returned show as Overdue.
  • Principal / Librarian / Teacher can click 📱 Parent next to overdue learner → WhatsApp opens with message: Your child has not returned Mathematics Grade 10 — Due 30 November — Please return tomorrow.
  • Click WhatsApp ALL Overdue Parents to message all overdue parents one by one.

Lost / Damaged

  • Learner loses book → Librarian marks LOST in Stock → Book removed from Available.
  • Learner must replace book or pay charge (e.g. R150).
  • Principal sees Total Lost Cost in Overdue + Lost tab.
  • If book is found later, Librarian clicks Restore.

14. FAQ

Can a learner borrow 2 different Titles?

Yes. One Learner One Title means: 1 copy of Mathematics + 1 copy of English = Allowed. 2 copies of Mathematics = Blocked.

Can a teacher issue a book for another teacher's subject?

No. Teacher can only issue their own subject. Librarian / HOD / Principal can issue any subject.

Can a teacher return a book for another subject?

Yes. Return has no subject limit. Anyone can return any book.

What if two learners have same name?

Allowed. They have different Learner IDs. Check ID + Class to tell them apart.

What if learner loses book?

Mark LOST in Stock → Learner pays / replaces → Principal sees Lost Cost in report.

What happens on 1 December?

All books not returned become Overdue. Do Stock Take after 30 November returns.

Can we add a new subject not in dropdown?

Contact Vusi Chauke — 078 023 3263. Do not type subject in other fields — It will break grouping.

How do we add a new school?

Contact Vusi Chauke — Xintimani Group. New school gets its own login + prefix (e.g. TP for THUTO PRIMARY).
