4. Librarian — Books, Learners, Users

📚 Add Books — Use Quantity (Do NOT Add 1 By 1)

  1. Librarian → Books → Check Starting Barcode — Auto-filled (e.g. TP000001). Do NOT change.
  2. Title: Mathematics Grade 10 • Subject: MATHEMATICS (dropdown) • Grade: 10 • Author: Maskew Miller • Group: FET
  3. Quantity: 5 → Check Preview: Will create: 5 copies — TP000001 to TP000005
  4. Click ADD BOOKS → Check: ✅ Added 5 copies
  5. Books List: Grouped row shows Qty: 5, Available: 5, Issued: 0. Click row to expand copies.
Common Mistakes:
❌ Adding 1 book at a time for 50 copies — Use Quantity.
❌ Typing subject "maths" — Use dropdown MATHEMATICS.
❌ Changing Starting Barcode — Use auto-filled.

👩‍🎓 Add Learners — Bulk Add

  1. Learners → Single: Name + Click AUTO ID → Add.
  2. Bulk: Grade + Class → Paste names (1 per line) → BULK ADD → IDs auto-created (e.g. 10A001, 10A002).
  3. Learner needs: Name, Grade, Class, ID. Phone (parent) optional but helps for WhatsApp.
  4. Duplicate ID → ⛔ Blocked. Duplicate Name → ✅ Allowed.

👩‍🏫 Add Users — Teachers, Librarian, HOD

  1. Users → Name + Email + Password + Role → Subject 1 (Required for TEACHER) → Save.
  2. Teacher with no subject → ⛔ Blocked.
  3. Reset password: Click 🔑 Reset 1234 → Password becomes 1234.
  4. Delete user: Click Delete → User cannot login anymore. Their issued books stay in system.

🏫 Add School (Principal Only)

Principal registers school in index.html → School gets Prefix (e.g. THUTO PRIMARY → TP) + DEMO 7 days free. After demo, Principal pays Vusi to activate. Librarian cannot add school.

5. Issue / Return — Camera Scan

📖 Issue (10 Seconds)

  1. Issue → Pick Learner (search name / ID / class) → Scan Book (camera or type barcode) → Check Title + Grade + Subject → ISSUE
  2. Due Date = 30 November (automatic).
  3. WhatsApp parent? Click Yes → WhatsApp opens → Send. Click No to skip.
  4. Learner now shows Issued: 1. Book shows ISSUED to that learner.

📥 Return (5 Seconds)

  1. Return → Scan barcode (or type) → Check Learner + Title → RETURN
  2. Book becomes AVAILABLE. Learner Issued count goes down.
  3. Anyone can return — Teacher, Librarian, HOD, Principal.

6. Teacher — My Class Only

  • Login as Teacher → See only my class (e.g. 10A, not 10B, not whole school).
  • Issue my subject → ✅ Allowed. Issue other subject → ⛔ Blocked.
  • Return any book → ✅ Allowed.
  • Cannot add / edit books, learners, users — Buttons disabled. Ask Librarian.
  • Cannot see other class's learners.
  • See my class % Retrieval: Issued, Returned, Still Out, %.
Teacher Daily Routine:
Morning: Open Teachers page → See Still Out list for my class.
During lesson: Issue books to learners who don't have them.
End of week: Chase learners with Still Out books. WhatsApp parents from list.

7. Principal — % Retrieval + Reports

📊 Dashboard — Read This Every Monday

% Retrieval = Returned ÷ Issued × 100
Example: Issued 120, Returned 98 → 82% Retrieval • Still Out 22 → 18% Outstanding
Green ≥90% • Orange 70–89% • Red <70% • Target 100% by 30 November
  • Top boxes: Total Schools? No — Total Books, Issued, Returned, Still Out, % Retrieval, % Outstanding.
  • By Group tab: Which Group / Subject is behind? (e.g. MATHEMATICS 88%, ENGLISH 65%)
  • By Class tab: Which Class is behind? (e.g. 10A 96%, 10B 75%)
  • By Teacher tab: Which Teacher is behind?
  • By Learner tab: Which Learner still has books? (Search name / ID)

📱 Send WhatsApp Report (To SGB / Circuit)

  1. Principal → Report tab → Phone: Type SGB / Circuit phone (e.g. 0780233263) → SEND WHATSAPP REPORT (Filtered) → WhatsApp opens with % Retrieval → Send.
  2. Report shows: School, % Retrieval, Issued, Returned, Still Out, By Group / Class.

🖨️ Print Report

  1. Principal → Report tab → PRINT REPORT → Print / Save as PDF.
  2. Give printed report to SGB meeting.

8. Stock — Stock Take, Lost / Damaged

📦 Stock Page — See All Books

Stock → Filter by Group → Grade → Subject → Title → See Qty, Available, Issued, Lost, % Retrieval per Title.
Low Stock: If Available is low (e.g. 2 left), order more.

📋 Stock Take (End Of Term)

  1. Stock → Stock Take → Filter to Grade / Subject → START CAMERA SCAN → Scan books on shelf → FINISH
  2. Found = Scanned. Missing = Not scanned (either issued to learner or lost).
  3. Check Missing list → Chase learners with those books.

😢 Lost / Damaged

  1. Stock → Lost / Damaged → Scan barcode → Reason LOST or DAMAGED → Learner + Charge (e.g. R150) → MARK LOST
  2. Book removed from Available. Learner shows Lost. % Lost goes up.
  3. Restore: Click ✅ Restore → Book back to Available (if found later).
Charge: Principal decides charge. Common: R150 for lost book. Tell parent via WhatsApp: "Your child lost [Title] — Please pay R150 or replace book."

9. Barcodes — Print A4

  1. Barcode → Filter to Title → Print → Check: 15 barcodes per A4, 3×5, Title + Barcode + School Name.
  2. Print on sticker paper or normal paper + cut + tape on book.
  3. Stick barcode on inside cover (not outside — Outside wears off).
  4. Test: Scan 1 barcode in Issue → Should find book.
  5. If printer is small / faint, increase print size in browser Print → Scale 100% → Background graphics ON.
Barcode Format: Prefix + Number. Example: THUTO PRIMARY → TP + 000001 = TP000001
Next book: TP000002, TP000003... System auto-increments. Do NOT reuse numbers.
