1. What Is Makhanani LTSM 2.0?

Makhanani LTSM 2.0 helps your school manage all LTSM books — textbooks, novels, dictionaries, study guides — from one place, on phone or computer.

  • Before: Paper registers, lost books, no one knows who has what.
  • Now: Stock is live. Issue a book → Stock goes down by 1 automatically. Return → Goes up by 1.
  • Flow: Teacher requests → HOD approves → Librarian issues → Learner returns → Stock updates.
💡 Golden Rule: Never issue a book without recording it in Issue. If it is not in the system, it does not exist.

5. Stock — Add Books, Edit Qty, Low Stock

Open: stock.html

Add A Book

  1. Book Title * — e.g. English Grade 10
  2. Author / Publisher — e.g. DBE / Oxford
  3. Category — Textbook / Novel / Dictionary / Study Guide
  4. Grade — Grade 8 to 12 / All Grades
  5. Barcode / ISBN — Scan or type
  6. Quantity * — e.g. 10
  7. Click ✅ ADD TO STOCK

Edit Quantity

Click ✏️ Qty next to book → Type new number → OK. Use this when books are lost, damaged, or new delivery arrives.

Delete Book

Click 🗑️ → Confirm. Only delete if book was added by mistake.

Status Meanings

  • ✅ IN STOCK — Qty 5 or more
  • ⚠️ LOW STOCK — Qty 1-4 — Order more soon
  • 🔴 OUT OF STOCK — Qty 0 — Cannot issue
💡 Search: Type title, author or barcode in Search box to filter instantly.

6. Issue / Return — The Daily Job

Open: issue.html

Issue A Book OUT

1. Learner Name * — Start typing, pick from list
2. Book Title * — Pick from list (shows only books in Stock)
3. Action = 📤 ISSUE OUT
4. Grade / Class — e.g. 10A
5. Barcode — Scan if available
6. Click ✅ SAVE ISSUE / RETURN
→ Stock automatically goes -1

Return A Book

Option A: In issue.html, do a new entry with Action = 📥 RETURN
Option B: In the table, click 📥 Return next to that learner's row
→ Stock automatically goes +1
⚠️ Never do this: Issue on paper only and "capture later". Capture at the moment you hand the book over.

7. Teacher — Request A Book

Open: teacher.html

  1. Click 📦 VIEW STOCK → Check if book is available
  2. Back to Teacher page → Book Title * → Learner / Class — e.g. Grade 10A / Thabo
  3. Click 📩 SEND REQUEST TO HOD
  4. Wait for HOD. Status: ⏳ PENDING → ✅ APPROVED or ❌ REJECTED
  5. If APPROVED, Librarian will issue the book to you / learner

8. HOD — Approve / Reject

Open: hod.html

  1. Click 📦 OPEN STOCK first — Check if book is in stock
  2. Go to ✅ Approvals — Teacher Requests
  3. For each PENDING request, click ✅ Approve or ❌ Reject
  4. Approved = Librarian can now issue. Rejected = Teacher sees ❌ REJECTED
💡 Best Practice: Check stock before approving. Do not approve if Qty = 0.

9. Librarian — Daily Workflow (Morning → Afternoon)

  1. Morning: Open librarian.html → Check Recent Issues from yesterday
  2. During Day: Issue books in issue.html as learners come. Use barcode scan if possible.
  3. Returns: As learners return, click 📥 Return immediately
  4. End of Day: Open stock.html → Check Low Stock ⚠️ → Tell HOD / Principal what to order
  5. Friday: Count physical books vs System Qty. If different, fix Qty with ✏️ Qty and tell Principal why.

10. Learners — Add & Manage

Open: learners.html or school_admin.html

  1. Learner Name * — e.g. Thabo Mokoena
  2. Grade — Grade 8-12
  3. Class — e.g. 10A
  4. Click ✅ ADD LEARNER
  5. To issue to that learner, click 📤 Issue Book next to their name → Goes to issue.html

Column Books Issued shows how many books that learner currently has out. If it is 3+ and they want another, ask HOD first.

11. Principal — Reports

Open: principal.html

  • Total Books: How many titles in stock
  • Issued Out: How many books are currently with learners
  • Pending Requests: Teacher requests waiting for HOD
  • Learners: Total learners in system
  • Recent Issues: Who took what, when
  • Pending HOD Requests: What is waiting

Use this every Monday morning to see if school is on track.

17. FAQ

Q: Can Teacher edit stock?
A: No. Teacher is View Only. Only Librarian / HOD / Admin can edit.

Q: What happens if I issue a book that is Out of Stock?
A: System will still save the issue, but Qty will stay at 0. Always check stock first.

Q: Can we use it on phone?
A: Yes. All pages work on phone, tablet and computer. Use Chrome.

Q: Is learner data safe?
A: Yes. See terms.html Section 7 (POPIA). Only authorised school staff can see it. We do not sell data.
