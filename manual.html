3. 📦 Stock — Add Books

  1. Go to 📦 STOCK
  2. Fill: Title e.g. English Grade 10, Author DBE, Grade, Qty e.g. 10
  3. Click 🎲 AUTO — NEXT BOOK NUMBER → System gives WHS000001
  4. Click ✅ ADD TO STOCK
  5. Book appears in list with barcode + Qty
⚠️ Do NOT type barcode manually if you can avoid it. Always use AUTO — it prevents duplicates. Book Number = Initials + 6 digits, auto +1 each time.

Edit Qty: Stock → ✏️ Qty → Type new qty → Save. Low Stock: Qty < 5 shows ⚠️ LOW STOCK — Order more.

4. 🔢 Barcode Format — Must Know

TypeFormatExample — WordsworthExample — Other School
📚 Book NumberFirst letter of EACH word in school name + 6-digit sequence autoWordsworth High School → WHS000001, WHS000002...George Sonto Secondary → GSS000001
🎓 Learner IDGrade + Class + 3-digit sequence autoGrade 10, Class A → 10A001, 10A002...Grade 8, Class B → 8B001
✅ Why this format? Book number tells you school + which copy. Learner ID tells you grade + class + which learner — no need to search name. Scan is instant.

5. 🖨️ Print Barcodes — A4 3x5 — 15 Per Page

For Books:
  1. Go to 🖨️ PRINT BARCODES A4 3x5 (Home / Stock / Issue)
  2. Type = 📚 BOOK Barcode
  3. School = Wordsworth High School (auto)
  4. Subject = e.g. English Grade 10, Grade = Grade 10, Author = DBE
  5. Start Number = 1 → Preview shows WHS000001
  6. How Many = 15 = 1 A4 page
  7. Click 👁️ PREVIEW BARCODE SHEET → Check 15 labels
  8. Click 🖨️ PRINT A4 NOW
For Learners — One Learner: Type = 🎓 LEARNER → Name = Thabo Mokoena → Grade 10, Class A, Start 1 → Preview = 10A001 → Print
For Learners — Whole Class (Batch):
  1. Type = 🎓 LEARNER, Grade 10, Class A
  2. Paste class list in 👥 Learner Batch — one name per line
  3. Click 👥 GENERATE BATCH FROM LIST → Auto: 10A001, 10A002, 10A003...
  4. Click 🖨️ PRINT A4 NOW
🖨️ Print Settings — Must Set: Paper = A4 • Margins = None • Scale = 100% • Background Graphics = ON • Use laser printer + sticker paper. Cut along lines → Stick book barcode on book cover (front, bottom corner). Give learner card to learner to keep in school bag.
💾 Save To Firebase: In Print page, click 💾 SAVE TO FIREBASE for books — it adds all printed books to Stock automatically, so Issue scan will find them.

6. ⚡ Double Scan — Issue In 2 Seconds — Librarian Daily Job

This is the fastest way. No typing.

STEP 1 — Scan Learner: Issue page → 📷 SCAN LEARNER CARD → → Point camera at learner card (10A001) → Learner name + ID + Grade auto-fill → Box turns ✅ green
STEP 2 — Scan Book: Issue page → 📷 SCAN BOOK BARCODE → → Point camera at barcode on book cover (WHS000001) → Book title + Book Number + Qty auto-fill → Box turns ✅ green
STEP 3 — Issue: Button turns green: ✅ ISSUE OUT NOW — English Grade 10 → Thabo Mokoena → Tap it → Done! Stock auto: 10 → 9. Form resets for next learner.
✅ Queue: Keep learners in line. Scan learner, scan book, Issue, next learner. 1 learner = ~5 seconds. 30 learners = ~3 minutes.

No Camera / Camera Blocked? Type Learner ID (10A001) in Learner ID box → Press Enter → Auto-fills. Type Book Number (WHS000001) in Book Number box → Press Enter → Auto-fills. Then click Save. Same result.

7. 🔙 Return Books

  1. Issue page → Same Double Scan: Scan Learner + Scan Book
  2. Change Action to RETURN
  3. Click ✅ SAVE ISSUE / RETURN → Stock auto: 9 → 10
  4. OR in Recent Issues list → Click 📥 Return next to that issue
⚠️ Always scan Return too — do NOT just put book back on shelf. If you don't scan Return, system still thinks learner has the book.

8. 🎓 Learners — Add + Print Cards

  1. Go to 🎓 LEARNERS
  2. Fill Name, Grade, Class → Click 🎲 AUTO — NEXT LEARNER ID → e.g. 10A001
  3. Click ✅ ADD LEARNER
  4. Bulk: Paste class list → 👥 ADD ALL + AUTO IDs → 10A001, 10A002...
  5. Click 🖨️ PRINT CARDS A4 3x5 → Print → Give cards to learners

9. 👔 HOD — Approve Teacher Requests

  1. Teacher: Go to 👩‍🏫 TEACHER → Request Book From HOD → Fill Book + Learner / Class → Send
  2. HOD: Go to 👔 HOD → See ⏳ Pending requests
  3. Check 📦 STOCK first — is book in stock?
  4. If YES → ✅ Approve → Librarian can issue. If NO → ❌ Reject

10. 🏫 Principal / School Admin — Reports

  1. Go to 🏫 PRINCIPAL or 🏫 SCHOOL ADMIN
  2. See: Total Books, Issued Out, Returned, Low Stock, Learners, Users
  3. Check Low Stock → Order more books
  4. Check Issues list → Who has books out longest
  5. Check Users → Set roles for new teachers

12. ✅ Daily Checklist — Librarian

🌅 Morning — Open Library
  • Open App → Login
  • Check Stock → Any Low Stock?
  • Check Pending Issues from yesterday
📚 During Day — Issue
  • Double Scan: Learner + Book → Issue
  • Keep queue moving — 5 sec per learner
🔙 End Of Day — Return
  • Double Scan Returns → Stock +1
  • Count books on shelf vs System Qty
🖨️ Weekly — Print
  • Print barcodes for new books
  • Print cards for new learners
  • Report Low Stock to HOD / Principal
✅ Golden Rule: Every book that leaves the library MUST be scanned. Every book that comes back MUST be scanned. No scan = Lost book.
