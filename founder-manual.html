3. Reset Password / Block / Unblock — 1 Minute

Most support messages are "I forgot my password". Fix in 1 minute, do not spend 20 minutes.

ProblemFix
Forgot PasswordSuper Admin → Users → Filter by School → Find user → 🔑 Reset Password to 1234 → Tell them: "Login with Email + Password 1234, then change it in Profile."
Set Custom PasswordSuper Admin → Users → ✏️ Set New Password → Type new password, e.g. School2026 → Tell them on WhatsApp (not in group)
Wrong EmailDelete user → Create new user with correct email in Quick Create / Librarian → Teachers. Do not edit email in Firebase directly.
Blocked UserSuper Admin → Users → Find user → ✅ Unblock
Teacher Can't See ClassSuper Admin → Users → Check Teacher's className — Must be e.g. 10A exactly. If blank, delete + re-add with Class.
Principal Left SchoolBlock old Principal → Create new Principal user with new Email + Password → Tell new Principal to change password.
Password Rules You Tell Schools: Min 6 characters, letters + numbers, e.g. School2026. Do NOT share with learners. Change in Profile after first login. Old PIN is now password — Same number works.
Security: Never send password in a group WhatsApp. Send 1-to-1 only. Never share Super Admin password. Change your own password monthly in Profile.

4. Quick Create School — After Payment

Use this when Principal paid via EFT / Cash and did NOT fill subscriptions form. Or when you want to create school fast.

  1. Super Admin → ➕ Quick Create School
  2. Fill: School Name, EMIS, Principal Name, Principal Email, Principal Phone, Principal Password (default 1234), Package, Status = ACTIVE
  3. Click ✅ CREATE SCHOOL + PRINCIPAL
  4. Copy Activation Message → WhatsApp to Principal
Quick Create vs Approve:
Approve = Principal filled form, password already created by them.
Quick Create = You create, you set password (1234), they change it in Profile.
