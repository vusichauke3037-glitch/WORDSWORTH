🚨 What To Do When Something Breaks

BreakDo
1 school cannot loginCheck: Is school SUSPENDED? Is user BLOCKED? Is PIN correct? Reset PIN to 1234.
All schools cannot loginCheck: Did you change GitHub file? Did Firebase rules change? Open Firebase Console → Rules → Set to Allow → Publish.
Page shows 404Check: File name spelling — librarian.html not librarian.htm. GitHub commit done? Wait 2 min for GitHub to deploy.
Revenue shows R0Check: Package spelling in school.html — Must be STANDARD, STARTER, or PREMIUM. Not "Standard R500".
WhatsApp not openingCheck: Phone has 10 digits, starts with 0. No spaces.
Golden Rule: Never fix live in front of Principal. Say: "Let me check and WhatsApp you in 10 minutes." Fix calmly, then WhatsApp fix.
