1. What Makhanani LTSM Is

Product: Learner & Textbook Management System for South African schools. 1 Subject per Learner rule, Barcode stickers 3x5 A4, A4 Issue/Return Slips, Subscription control, Audit Logs.
Tech: HTML + Firebase Auth + Firestore. No server. All 7 pages share cloud.js. Data path: schools/EMIS_xxx/learners, books, issues, staff, logs + dbe_schools master list.
Business Model: Schools pay Setup + Monthly/Yearly Subscription. You control access via subscription.status in Firestore.

2. Your Firebase Setup (One Project For All Schools)

Project: makhanani-ltsm. Auth: Email/Password only. Firestore: Rules = Auth required for schools/*, Public read for dbe_schools, Logs Create-only.
Collections:
1. dbe_schools/{EMIS} = {emis, name, town, province} — Master DBE list. Schools select from this.
2. schools/EMIS_xxx = {name, emis, town, province, subscription:{plan, status, end, setup, amount}}
3. schools/EMIS_xxx/staff = Doc ID = Auth UID, {name, email, role, status}
4. schools/EMIS_xxx/learners, books, issues, logs = School data.

3. Onboarding A New School — 10 Min Checklist

1. Get EMIS + School Name + Town + Principal Name + Email + Phone.
2. In Firebase Auth → Create User → Principal email + Temp Password (e.g. Temp1234) → Copy UID.
3. In Firestore → dbe_schools → Create doc ID = EMIS → Add fields.
4. In Firestore → schools → Create doc ID = EMIS_xxx → Add subscription {plan:TRIAL, status:TRIAL, end: 30 days later, setup:0, amount:0}.
5. In schools/EMIS_xxx/staff → Create doc ID = UID → {name, email, role:PRINCIPAL, status:ACTIVE}.
6. Send school: ZIP (v1.87) + Link + Principal Guide + Temp Password via WhatsApp.
7. Tell Principal: Login → Change password via Forgot Password → Add staff in Admin → Add learners/books.
8. After 7 days: Check logs — if school active, send invoice. Change subscription to ACTIVE + set end date.

4. Pricing & Subscription Control

Recommended Pricing (Adjust to your area):
Setup Once: R500 - R1,500 per school (includes training + printing first stickers)
Monthly: R299 - R499 / school OR Yearly: R2,999 - R4,999 / school (2 months free)
Control: In Firestore schools/EMIS_xxx → subscription.status = TRIAL / ACTIVE / EXPIRED / PENDING / BLOCKED. If EXPIRED/BLOCKED, school sees banner + cannot issue. Never delete school data — just change status.
Renewal: When paid, set status=ACTIVE, end = new date, amount = paid amount. Log it in your own sheet.

5. Support — What You Do / Don't Do

YOU DO: Reset Principal password (Firebase Auth), Fix EMIS selection, Fix subscription, Add school, Fix duplicate barcode (delete duplicate in Firestore), Train Principal.
YOU DON'T: Delete learner/book that is OUT, Share your Firebase Console login, Give schools your Service Account key, Edit school data without asking Principal.
Common Fixes: “Account NOT for...” = Wrong EMIS selected OR staff UID mismatch. “Missing permissions” = Rules not published OR not logged in. “Stickers not 3x5” = Old file, send v1.87 ZIP again.

6. Money, Records & Growth

Keep a Google Sheet: School | EMIS | Principal | Phone | Plan | Status | End Date | Amount Paid | Date Paid | Notes. Check every Monday: Schools expiring in 7 days → Send WhatsApp reminder. Schools with 0 logs in 14 days → Call Principal — they are stuck, offer free 10-min call.
Growth: Start with 3-5 schools in one circuit. Get 1 testimonial video from Principal. Use it to get next 10 schools. Do NOT give free forever — TRIAL max 30 days.

⚠️ Founder Rules: 1) Never share Firebase Console login. 2) Never delete Firestore data without backup (Export weekly: Firestore → Export). 3) Always test new version on TEST SCHOOL (EMIS 999999999) before sending to real schools. 4) Keep v1.87 ZIP as master — never edit live files directly.
✅ Weekly Founder Routine (30 min): Mon: Check expiries → Tue: Check logs / stuck schools → Wed: Backup Firestore → Fri: Send 1 WhatsApp tip to all Principals (e.g. “Return overdue books today”).
