📱 How to Install as App

Android (Chrome): Open this page → Tap ⋮ top right → Add to Home Screen / Install App → Tap Install.

iPhone (Safari): Open this page in Safari → Tap Share (square + arrow) → Add to Home Screen → Add.

After install: You will see your logo.png icon on Home Screen. Tap it — opens full-screen, no browser bar, works offline.

Offline tip: Open Issue page once with WiFi in the morning to load learners/books. Then you can Issue / Return all day even if WiFi dies.
