📚 What Is Makhanani LTSM?

Makhanani LTSM helps a school track every textbook, every learner, and every return — so no book goes missing.

  • Issue / Return in seconds: Scan learner card + scan book — done.
  • Barcodes: 3 across x 5 down = 15 labels per A4. Stick on books + learner cards. Scan with any phone camera, or type the number.
  • Dashboards: Principal sees Totals + Issued + Returned + Overdue + Missing per Grade / Subject.
  • Offline Mode: Issue / Return works without internet — saved on phone, auto-syncs when back online. No tap needed.
  • Works on a phone: No app to install. Opens in browser. Works on Android + iPhone. Works with low data.
Due Date: 30 November — Every book must come back. Return is NEVER blocked — anyone can return any book.
