👩‍🎓 Duplicate Learners — Same Name + Class Twice

Duplicate = Same Name + Same Class, but different Learner ID. Example: THABO MOKOENA — 4A appears twice as L001 + L002. Keep 1, delete the other. Check Issues first — If both IDs have issues, keep the ID with issues.

📚 Duplicate Books — Same Title + Subject Twice

Duplicate = Same Title + Same Subject, but different Book ID. Example: MATHS GRADE 4 — MATHS appears as BK001 + BK002. Keep 1, delete the other. Check Issues first — If both IDs have issues, keep the ID with issues.

📕 Orphan Issues — Issue With Learner / Book That Does Not Exist

Orphan = Issue Learner ID not in Learners, OR Issue Book ID not in Stock. Example: Issue L999 — Learner L999 does not exist. Fix by adding learner / book, or delete orphan issue.
IssueLearnerBookProblemAction

❌ Missing Data — No Class / No Title / No Status / No Role

Missing = Learner with no Class, Book with no Title, Issue with no Status, User with no Role. These break Retrieval % + Reports. Fix by editing in Teacher / Librarian / Users.
