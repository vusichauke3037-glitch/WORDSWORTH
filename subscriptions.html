📋 All Subscriptions — Auto Status + Auto-Suspend + Grace 7 Days

Status is AUTO: TRIAL = DEMO 7 days, NO grace • ACTIVE = Paid + Not Expired • EXPIRING = Expires in ≤7 days • GRACE = Expired but still in Grace 7 days (can still login, Day 1 reminder only) • EXPIRED = Past End + Grace 7 days → BLOCKED • SUSPENDED = You suspended it → BLOCKED.
Expiry: DEMO = Start + 7 days • Monthly = Start + 1 month • Yearly = Start + 12 months. Renew adds 1 month / 12 months from End Date. Grace Ends = End + 7 days.
✅ AUTO-SUSPEND ON — When a school expires + grace 7 days ends, it is auto-suspended on next login / page load. Untick to turn OFF (manual only).

⚙️ Subscription Settings — Grace 7 Days + Auto-Suspend + Day 1 Reminder

Grace Period = Extra days after End Date where school can STILL login, but sees warning.
Example: Grace 7 days → Ends 06 Dec → Can still login until 13 Dec → On 14 Dec → BLOCKED.
Grace 0 days → Blocked on End Date + 1 day.
Demo / Trial has NO grace — Trial ends = Blocked immediately.
Day 1 Reminder: On first day of grace only, school sees pop-up + alert saved for Super Admin (0780233263). Day 2-7: No reminder, quiet.
✅ Auto-Suspend ON — Auto-block expired schools on login / page load.
How Auto-Suspend Works:
1. Login Check (index.html): Teacher / Principal / Librarian tries to login → System checks subscription for their school → If EXPIRED + Grace 7 days ended OR SUSPENDED → Login BLOCKED → Shows WhatsApp Renew button to 0780233263.
2. Page Check (nav.js guardPage): If teacher is already logged in and subscription expires while they are using it → Next page they open → Logged out → Back to login.
3. Super Admin BYPASSES — Can always login to renew.
4. Renew → End extends + Unsuspends automatically → School can login again.
5. Grace Day 1: First day of grace → School sees reminder + Alert saved to Firebase graceAlerts → Super Admin sees it on Super Admin Dashboard + Subscriptions top card → 1-click WhatsApp to school.
