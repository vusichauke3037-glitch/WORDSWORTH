How book barcode works: Each book copy gets 1 unique code — e.g. BK001 or 10AB001. Teacher scans this barcode in Home → Book opens → Issue to learner in 10 seconds. Same title, different copies = Different codes. Example: 5 copies of Maths Grade 10 = BK001, BK002, BK003, BK004, BK005.

📱 How To Scan + Stick Book Barcode

  1. Print labels from this page — 15 per A4 page, cut along dashed lines.
  2. Stick 1 label inside front cover, top right — Not on spine, not over text.
  3. Cover with clear tape — Protects barcode from tearing / water.
  4. Teacher opens `home.html` → Search box at top.
  5. Scan book barcode with phone camera / scanner — Code `BK001` types itself.
  6. Book opens → Click Issue → Scan learner barcode `10A001` → Done in 10 seconds.
  7. Return: Same — Scan book → Click Return.
No scanner? Type code manually: In Home Search, type `BK001` → Press Enter → Book opens.

⚡ Quick Rules

  • 1 copy = 1 code. 5 copies of same title = 5 different codes.
  • Lost label? Use Tab 1 Book → Same title + Same code → Print again. Do NOT make new code.
  • New book? Use next number — If last book is BK015, new book is BK016.
  • Print test first: Print 1 page on plain paper, scan 1 barcode with phone camera — Must show code. Then print on sticker paper.
  • Stick inside cover + Cover with clear tape — Lasts 1 year.
