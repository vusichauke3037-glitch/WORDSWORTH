⚖️ 2. Professional Registration — What Schools Should Know

Software development is NOT a regulated profession in South Africa.
There is no statutory council / licence that a software developer must hold to build, sell, or support software — unlike doctors (HPCSA), lawyers (Legal Practice Council), engineers (ECSA), or accountants (SAICA).
ProfessionStatutory BodyMust Register?
DoctorHPCSAYes
LawyerLegal Practice CouncilYes
Engineer (Professional Engineer)ECSAYes, to use the title
Software DeveloperNone — No statutory bodyNo — No licence required
What this means for your school:
• Xintimani Group does NOT need a statutory developer licence to build Makhanani LTSM.
• Voluntary bodies like IITPSA (Institute of Information Technology Professionals South Africa) exist for networking / CPD, but membership is voluntary, not a legal requirement.
• What your school SHOULD check instead: CIPC registration, SARS tax compliance, POPIA data protection, a written agreement, and references from schools already using the system.
• This Company Profile + a Service Agreement + a live demo at Wordsworth High School are the correct proof — not a developer licence certificate.

📚 3. Makhanani LTSM — What It Does

Makhanani LTSM — Learner and Textbook Management System — helps a school know, at any time: Which learner has which book? Which books are overdue? Which books are missing?

FeatureWhat It Means For Your School
📚 Issue / ReturnScan a learner card + scan a book — book is issued in seconds. Return the same way. No paper register.
🎓 LearnersAdd learners, bulk upload via CSV, auto Learner ID. Each learner has a barcode card.
📖 TextbooksAdd textbooks, bulk upload via CSV, auto Book Number. Each book has a barcode label.
🏷️ Barcode Labels — 3x5 A4Print 15 labels per A4 page. Stick on books + learner cards. Scan with any phone camera.
👩🏾‍🏫 Principal DashboardPrincipal sees: Total learners, Total books, Issued, Returned, Overdue, Missing — per Grade / Subject.
📚 Librarian DashboardLibrarian sees: Who has which book? Search by learner, book, title, or grade.
🔒 Roles + PrivacyTeacher sees Own Subject only. Librarian / HOD sees Any Subject. Principal sees Dashboard + Pricing. Admin sees All Schools + Users. Pricing is private — Teachers / Librarians cannot see it.
🟠 Return Only ModeIf subscription is Suspended / Expired, school can still RETURN books — never blocked. Issue / Add is paused until reactivated.
📱 Works On A PhoneNo app to install. Opens in browser. Works on Android + iPhone. Works with low data.
Due Date: 30 November — Every book must come back.
Return is NEVER blocked — anyone can return any book.

🔒 5. POPIA + Data Protection — How We Protect Learner Data

Xintimani Group complies with the Protection of Personal Information Act (POPIA), Act 4 of 2013. Learner data belongs to the school, not to Xintimani Group. We are the operator, the school is the responsible party.
POPIA PrincipleHow Makhanani LTSM Handles It
What data do we store?Only what the school needs to track books: Learner Name, Grade, Class, Learner ID, Book Title, Subject, Grade, Book Number, Issue / Return dates. No ID numbers, no medical info, no bank details.
Who can see it?Only users the school’s Admin adds, with the correct Role. Teacher = Own Subject only. Librarian / HOD = Any Subject. Principal = Dashboard. Admin = All Schools + Users. No public access.
Where is it stored?Secure cloud database (Firebase / Google Cloud) with login + password. Only logged-in users for that school can see that school’s data. One school cannot see another school’s learners.
How is it protected?Password login, Role check on every login, no public links to learner lists, no sharing of learner data with third parties without school consent.
How long is it kept?As long as the school uses the system + as required by school records policy. School can request export / deletion on exit.
What if there is a breach?School will be notified without delay, and the Information Regulator will be notified as required by POPIA.
Can a parent / learner ask what data we hold?Yes — via the school. The school, as responsible party, handles access / correction requests.
Do we sell learner data?Never. Learner data is never sold, never used for marketing, never shared with advertisers.
School’s responsibility: School must only add users who need access, use strong passwords, and not share login details. Admin must remove users who leave the school.
