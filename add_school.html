⚡ Quick Rules — School

  • 1 school = 1 Prefix. Makhanani Primary School = MPS. Never use same prefix for 2 schools.
  • Textbook Numbers: Prefix + 6 Digits — MPS school = MPS000001, TSS school = TSS000001. No clash.
  • Learner ID: Grade + Class + 3 Digits — 10A001 — Same format for all schools, but separated by School ID.
  • Login: Teacher logs in with Email + Password + School is auto-linked. Teacher sees ONLY their school's learners / textbooks.
  • Delete school? Only if no learners / textbooks yet. Otherwise keep it — Data is linked to School ID.
