📚 Makhanani LTSM — USER MANUAL v1.87

For Principals • Librarians • Teachers • Full System Guide

1. Login & School Selection

Open link → STEP 1: Search by EMIS / Name / Town → Click Select → STEP 2: Email + Password → Login. If wrong EMIS, click Switch School. Forgot Password: Type email → Forgot Password? → Check email.
Roles: PRINCIPAL = All pages + Admin + Approve staff + Subscription. LIBRARIAN = Issue/Return + Damaged/Lost + Learners/Books. TEACHER = Issue/Return + View.

2. Home Page (index.html)

Shows: Books OUT, Overdue, Available, Issued Today, Subscription banner. Top bar: ☁️ Cloud: Connected — School (EMIS xxx) = Good. If red, check internet. Buttons: Go to Learners, Books, Issue, Librarian, Admin, Principal. SYNC STATUS = Check cloud connection.

3. Learners (learner-barcode.html)

Add One: Name + Grade + Class (e.g. 10A) → Add Learner → Barcode auto LRN-G10-0001. Add Bulk: Paste 30 names (1 per line) → Grade + Class → Add All Names. Search: Type name / barcode / grade to filter. Print Stickers: Click Print Stickers 3x5 A4 → 15 per page (3x5) → Cut + stick on learner card. Delete: Only if learner has NO books OUT. Ask Principal if unsure.

4. Textbooks (textbook-barcode.html)

Add: Title + Subject + Grade + Qty → Add Book(s) → Barcodes auto BK-ACC-G10-0001 → 0030. Subjects: Use codes: ACC, ENG, MATH, PHY, etc. Search: By title / barcode / subject / grade. Print Stickers: Same 3x5 A4. Stick inside front cover. Condition: Good / Fair / Damaged / Lost.

5. Issue / Return (issue.html) + Librarian (librarian.html)

ISSUE: Scan Learner Barcode + Book Barcode → Check names on screen → Pick Due Date (14 days) → ISSUE BOOK → Print Slip → Learner signs. Rule: 1 Subject per Learner — system BLOCKS 2nd same subject.
RETURN: Return section → Scan Book Barcode ONLY → Pick Condition → RETURN BOOK → Print Return Slip.
DAMAGED / LOST: In Librarian page → Damaged/Lost section → Scan Book → Choose Damaged/Lost/Good → Mark. Damaged books will NOT issue until marked Good.
OVERDUE: List shows learners past Due Date. Tell Principal.

6. Admin (admin.html) — Principal Only

Add Staff: Name + Email + Role + Temp Password → Save Staff. New staff must use Forgot Password to set own password. DBE Schools: View master list. Subscription: View plan/status/end. Cannot change subscription — contact Makhanani.

7. Principal Dashboard (principal.html) — Principal Only

See: Total Learners, Books, OUT, Overdue, Damaged, Lost, Issued Today. Approve Staff: If teacher shows PENDING → Approve → Becomes ACTIVE. Overdue Report: Print / share with teachers. Logs: See who did what (Issue, Return, Add). Subscription: If EXPIRED/PENDING, contact Makhanani to renew.

8. Printing Guide

Stickers: A4, Margins Default, Scale 100%, Background Graphics ON → 3 across x 5 down = 15 per page. Slips: A4, 1 page only, Margins Default. Always check Print Preview before printing bulk.

9. Troubleshooting

Account NOT for...: Wrong EMIS selected → Switch School. Book already OUT: Book with another learner → Search who has it. Learner/Book NOT FOUND: Wrong EMIS or not added → Ask Principal to add. Cloud Error: Check internet, reload. PWA: Install via Chrome → Add to Home Screen for app icon.
