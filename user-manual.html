1. What Is Makhanani LTSM?

Makhanani LTSM is a Library + Textbook system on your phone. No app to install. No computer needed.

You use it to:

  • Issue a book to a learner in 3 seconds
  • Return a book in 2 seconds
  • See who has which book, and who is overdue
  • WhatsApp a parent in 1 click if a book is overdue

Issue Rules:
• 1 book = 1 issue. If learner needs 3 books, issue 3 times.
• Due date = Automatic, 14 days from today.
• If book is already OUT, system warns you. Do not issue same barcode twice.
• If learner has no phone, parent phone is blank — Add phone in Librarian → Learners to WhatsApp parent.

8. Common Problems

ProblemFix
