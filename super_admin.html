👩‍🏫 TEACHER MANUAL — Makhanani LTSM 2.0

Company: Xintimani Group Holdings (PTY)Ltd • Reg: 2026/934898/07 • Tel: 078 023 3263 • Email: vusichauke3037@gmail.com

Your Job: Request books, issue to YOUR class only, return books.

  1. LOGIN: Open makhanani-ltsm.web.app/login.html → Type email + password → You land on Teacher page. If you land elsewhere, tell Super Admin your role is wrong.
  2. REQUEST: Tap REQUEST → Choose Subject, Grade, Class, Book Title, Qty Needed → Submit. Wait for HOD.
  3. CHECK MAX: Your class shows MAX (approved by HOD) and Ever Issued. You CANNOT issue more than MAX.
  4. ISSUE: Tap ISSUE → Search learner by name / ID → Type or scan Book No → Check Book No is correct and not already issued → Confirm. Book No must be unique.
  5. RETURN: Find learner / book → Tap RETURN → Book goes back to Available, but Ever Issued does NOT go down.
  6. PROBLEMS: MAX reached? Ask HOD to increase MAX. Book No already issued? Do NOT issue same Book No twice — find another copy. Wrong class? You can only see YOUR class.

🔒 Rules You Must Know: MAX block, Return does NOT free slot, Book No unique, Teacher only own class, Due 30 Nov every year.
