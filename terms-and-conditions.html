2. What The Service Is

Makhanani LTSM helps a school track every textbook, every learner, and every return — so no book goes missing.

  1. Issue / Return: Scan a learner card + scan a book — book is issued in seconds. Return the same way.
  2. Learners: Add learners manually or bulk CSV upload. Auto Learner ID. Each learner has a barcode card.
  3. Textbooks: Add textbooks manually or bulk CSV upload. Auto Book Number. Each book has a barcode label.
  4. Barcode Labels: Print 3 across x 5 down = 15 labels per A4 page. Stick on books + learner cards. Scan with any phone camera, or type the bottom number manually.
  5. Dashboards: Principal sees Totals + Issued + Returned + Overdue + Missing per Grade / Subject. Librarian sees Who Has This Book?
  6. Roles + Privacy: Teacher = Own Subject only. Librarian / HOD = Any Subject. Principal = Dashboard + Pricing. Admin = All Schools + Users. Pricing is private — Teachers / Librarians cannot see it.
  7. Works on a Phone: No app to install. Opens in browser. Works on Android + iPhone. Works with low data.
Due Date: 30 November — Every book must come back. Return is NEVER blocked — anyone can return any book.

3. Accounts + Roles — Who Can Do What

  1. The school’s Admin creates Users. Each User gets an Email + Password + Role.
  2. Role must match what Admin gave you. If you pick the wrong Role at login, you will see: Role mismatch — Admin gave you: [Correct Role]. Pick the correct Role and login again.
  3. Users must keep passwords secret. Do NOT share logins. If a User leaves the school, Admin must remove that User immediately.
  4. Admin: Can create / edit schools, users, plans, subscriptions, and see all schools.
  5. Principal: Can view Dashboard + Pricing. Cannot add learners / books. Cannot see Admin Checklist / Audit / Financial Projection.
  6. Librarian / HOD: Can add learners / books, Issue / Return any subject, view Dashboards.
  7. Teacher: Can Issue / Return Own Subject only. Cannot see pricing. Cannot add learners / books unless Admin gives Librarian / HOD role.
  8. If a User misuses the system, Admin may suspend that User. Xintimani Group may suspend a school if the school breaks these Terms.
School is responsible for its Users. If a Teacher shares a password and someone else deletes / changes data, the school is responsible — not Xintimani Group.

5. Return Only Mode — Subscription Suspended / Expired

  1. If Subscription is Suspended / Expired, system goes to 🟠 RETURN ONLY MODE.
