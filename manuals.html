🚀 1. START HERE — FIRST TIME — 5 MINUTES

What Is Makhanani LTSM 2.0?

System to request, approve, and track LTSM / Textbooks / Workbooks for Grade 4 to 12, ALL CAPS Subjects, Classes A to J. Teacher requests → HOD approves → Librarian issues → Principal / Super Admin sees all.

Flow — In Order

Step 1: Super Admin creates Users in USERS page — Teacher, HOD, Librarian, Principal.
Step 2: Teacher logs in → TEACHER → Picks 1 CAPS Subject + 1 Class (Grade 4-12) → Types Book → Submit.
Step 3: HOD logs in → HOD → Sees only YOUR Subjects + YOUR Classes → Approve / Reject.
Step 4: Librarian logs in → LIBRARIAN → Sees Approved → Issues books → Marks ISSUED.
Step 5: Principal / Super Admin → HOME / PRINCIPAL → Sees ALL Grades 4-12 + ALL Subjects + Counts.

👑 2. SUPER ADMIN / PRINCIPAL MANUAL

1. Login: Go to login.html → Enter your Email + Password → You go to HOME.
2. HOME: Check Welcome VUSI CHAUKE — SUPER_ADMIN — RANK 6 + DEBUG: ✅ Firebase Live. If you see classes.join is not a function, go to USERS → EDIT yourself → Tick ALL SUBJECTS + ALL 90 CLASSES → UPDATE.
3. Add Users: Tap USERS → → Fill form → Save. After each save, Firebase logs you out of new user — Login again as YOU. This is normal.
4. Check All: HOME shows Total Users + Total Requests + Pending. PRINCIPAL page shows ALL Grades 4-12.
⚠️ Never share your Super Admin password. If you forget it, reset in Firebase Console → Authentication.

👩‍🏫 4. TEACHER MANUAL

1. Login → HOME shows: TEACHER — MATHEMATICS + Your Classes.
2. Tap TEACHER → → Subject dropdown is LOCKED to YOUR CAPS Subject — e.g. MATHEMATICS. You cannot pick another subject.
3. Class dropdown shows ONLY YOUR Classes — e.g. GRADE 10 10A — FET, GRADE 10 10B — FET. If dropdown says NO CLASSES ASSIGNED, ask Admin to tick classes for you in USERS.
4. Type Book: e.g. MATHEMATICS GRADE 10 LEARNER BOOK → Qty: 30 → SUBMIT REQUEST → You see ✅ Request Saved.
5. Track: Below form, My Requests table shows Status: PENDING → APPROVED → ISSUED.
Teacher Rule: 1 Subject only. If you need 2 subjects, tell Admin to change you to HOD.

📚 5. HOD MANUAL — MULTI SUBJECT + MULTI CLASS

1. Login → HOME → Tap HOD — MATHEMATICS + PHYSICAL SCIENCES →
2. Heading: Top shows 📚 HOD — MATHEMATICS + PHYSICAL SCIENCES — MAKHANANI LTSM 2.0 — All your CAPS subjects, not 1.
3. Select Subjects: Box 1 — Tick / Untick — e.g. Untick PHYSICAL SCIENCES → Heading becomes HOD — MATHEMATICS → Requests filter to MATHEMATICS only. Tick it back → Both show.
4. Select Grades / Classes: Box 2 — Tick Grades 10-12 ✅ or single classes — e.g. 10A, 10B — Requests filter to those classes only.
5. Approve: In Requests table, approve only requests where Subject + Class match YOUR subjects + classes. You will NOT see other HOD's subjects.
Example: HOD for MATHEMATICS + PHYSICAL SCIENCES, Grades 10,11,12 will see: MATHEMATICS 10A, PHYSICAL SCIENCES 11B — But NOT ENGLISH 10A.

📖 6. LIBRARIAN MANUAL

1. Login → Tap LIBRARIAN →
2. You see ALL Grades 4-12 + ALL CAPS Subjects — Because Librarian = ALL.
3. Filter by Subject / Grade / Class to find Approved requests.
4. Issue: When you give books to teacher, mark request as ISSUED + Enter Qty Issued.
5. Stock: Check stock before issuing. If stock is 0, do NOT issue — Tell HOD / Admin to order.

🏫 7. PRINCIPAL MANUAL

1. Login → HOME → Tap PRINCIPAL →
2. You see ALL — ALL Grades 4-12, ALL CAPS Subjects, ALL Teachers, ALL Requests.
3. Approve: You can approve any request, any subject, any grade.
4. Add Users: Like Super Admin, you can add Users — Tap USERS →
5. Reports: Check Counts: Total Users, Total Requests, Pending — Use for SMT meetings.
