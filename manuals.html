🚀 1. START HERE — FIRST TIME — 5 MINUTES

What Is Makhanani LTSM 2.0?

System to request, approve, and track LTSM / Textbooks for Grade 4 to 12, ALL CAPS Subjects, Classes A to J. Teacher requests → HOD approves → Librarian issues → Principal / Super Admin sees all.

Flow — In Order

Step 1: Super Admin creates Users in USERS — Teacher, HOD, Librarian, Principal.
Step 2: Teacher → TEACHER → Picks 1 CAPS Subject + 1 Class (Grade 4-12) → Types Book → Submit.
Step 3: HOD → HOD → Sees only YOUR Subjects + YOUR Classes → Approve / Reject.
Step 4: Librarian → LIBRARIAN → Sees Approved → Issues → Marks ISSUED.
Step 5: Principal / Super Admin → HOME / PRINCIPAL → Sees ALL Grades 4-12 + ALL Subjects.

👩‍🏫 4. TEACHER MANUAL

1. Login → Auto-go to TEACHER → Shows: TEACHER — MATHEMATICS + Your Phases.
2. Subject is LOCKED to YOUR CAPS Subject — e.g. MATHEMATICS. Cannot pick another.
3. Class dropdown shows ONLY YOUR Classes with correct Phase: GRADE 4 4A — INTERMEDIATE PHASE / GRADE 8 8A — SENIOR PHASE / GRADE 11 11A — FET PHASE. If NO CLASSES ASSIGNED, ask Admin to tick classes in USERS.
4. Type Book: e.g. MATHEMATICS GRADE 10 LEARNER BOOK → Qty 30 → SUBMIT → ✅ Request Saved.
5. Track: My Requests shows Status: PENDING → APPROVED → ISSUED.

📚 5. HOD MANUAL — MULTI SUBJECT + MULTI CLASS

1. Login → Auto-go to HOD → Tap HOD — MATHEMATICS + PHYSICAL SCIENCES →
2. Heading: 📚 HOD — MATHEMATICS + PHYSICAL SCIENCES — All your CAPS subjects.
3. Subjects: Tick / Untick — Untick PHYSICAL SCIENCES → Heading becomes HOD — MATHEMATICS → Requests filter to MATHEMATICS only.
4. Phases / Classes: Buttons: 4-6 INTERMEDIATE ✅ / 7-9 SENIOR PHASE ✅ / 10-12 FET ✅ → Requests filter to those phases only.
5. Approve: Approve only where Subject + Class match YOUR subjects + classes. You will NOT see other HOD's subjects.

📖 6. LIBRARIAN MANUAL

1. Login → Auto-go to LIBRARIAN → You see ALL Phases + ALL Subjects + ALL 90 Classes.
2. Dashboard: 3 Boxes: INTERMEDIATE 4-6 / SENIOR PHASE 7-9 / FET 10-12 — Counts per phase.
3. Filter by Phase / Grade / Status. Tap 📗 4-6 INTERMEDIATE to see only Grade 4,5,6.
4. Issue: Only when Status = APPROVED → Tap 📖 ISSUE → → Enter Qty → Status becomes ISSUED.
5. Stock: Type book title → Check stock before issuing. If 0, do NOT issue — Tell HOD / Admin.

🏫 7. PRINCIPAL MANUAL

1. Login → Auto-go to PRINCIPAL → You see ALL — ALL Phases, ALL Subjects, ALL Grades 4-12.
2. Dashboard: 3 Boxes: INTERMEDIATE 4-6 / SENIOR PHASE 7-9 / FET 10-12 + Pending per phase.
3. Approve: You can approve ANY PENDING request, any subject, any grade — Even if HOD has not approved.
4. Add Users: Tap USERS → — Like Super Admin.
5. Reports: Check Counts for SMT: Total Users, Total Requests, Pending, Approved, Issued, Rejected. Tap 🖨️ PRINT REPORT.
