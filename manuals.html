1. USER MANUAL — How To Use Makhanani LTSM 2.0

Read ONLY your role below. Other roles are hidden for you. If you are Principal / Admin / Super Admin, you will see all roles — Use that to train staff.

👩‍🏫 TEACHER — Rank 1 — My Classes + My Subjects Only

Step 1 — Login: Go to login.html → Type Email + Password given by Admin → LOGIN → You go to Teacher page.
Step 2 — Check My Classes: Top shows MY CLASSES — e.g. 4J, 10J — If it shows ⛔ NO CLASSES — ASK ADMIN — Ask Admin to assign classes in Users page.
Step 3 — Check My Subjects: Top shows MY SUBJECTS — e.g. MATHEMATICS — If ⛔ NO SUBJECTS — ASK ADMIN.
Step 4 — Add Learner: Teacher → Add Learner → Name + Grade + Class → ADD → Learner ID auto-created — e.g. Grade 10 + Class 10J → 10J001 — Format: Grade + Class Letter + 001 — NOT 1010J001.
Step 5 — Issue Book: Teacher → Issue → Class → Learner → Subject → Book → CHECK + ISSUE → Goes to HOD — PENDING.
Step 6 — Return Book: Teacher → Return → Learner → Book → RETURN → Book becomes AVAILABLE.
Step 7 — Scan: Teacher → Scan Barcode → Scan book barcode or learner ID → Issue / Return in 1 tap.
Rules: You see ONLY your classes + subjects. You cannot issue a subject you do not teach. You cannot add learner to a class you do not teach. Bulk Learners: Own classes only.

📚 LIBRARIAN — Rank 2 — All Classes 4A-12J — All Subjects

Step 1 — Login: login.html → Email + Password → LIBRARIAN page.
Step 2 — Add Book: Librarian → Add Book → Subject + Grade + Title → ADD → Barcode auto-created — e.g. WORDSWORTH HIGH SCHOOL → WHS000001 — Format: Prefix (First Letter Of Each Word) + 6-Digit — NOT WHS00001.
Step 3 — Issue Any: Librarian → Issue Any → Any Class → Any Learner → Any Subject → Any Book → ISSUE → Goes to HOD — PENDING.
Step 4 — Lost / Damaged: Librarian → Stock → Book → Mark LOST or DAMAGED → Book removed from AVAILABLE.
Step 5 — Print Barcode: Librarian → Barcode Print → 1 Label or A4 3x5 (15 labels) → Print → Stick on book.
Rules: Librarian sees ALL classes + ALL subjects. Librarian can issue to any learner. Librarian does NOT need HOD approval to add book — Only to issue.

✅ HOD — Rank 3 — My Subjects Only — Approve / Reject

Step 1 — Login: login.html → Email + Password → HOD page.
Step 2 — Check My Subjects: Top shows HOD: MATHEMATICS, PHYSICAL SCIENCES, LIFE SCIENCES — You approve ONLY these.
Step 3 — Approve: HOD → Pending Issues → Tick → APPROVE → Book becomes ISSUED.
Step 4 — Reject: HOD → Pending Issues → Tick → REJECT → Book becomes AVAILABLE again.
Rules: HOD cannot approve a subject they do not oversee. HOD cannot approve if book is already ISSUED / LOST.

👑 PRINCIPAL — Rank 4 — All Subjects, All Grades, All Classes

Step 1 — Login: login.html → Email + Password → PRINCIPAL page.
Step 2 — Overview: Principal → KPI: Total Books, Total Learners, Issued, Available — Filter by Grade / Class / Subject.
Step 3 — Export: Principal → EXPORT CSV → Save for SGB / District.
Rules: Principal sees ALL. Principal does NOT see Founder / Marketing / Financial / Employment — Those are Super Admin only. Principal cannot create users — Admin does that.

⚙️ ADMIN — Rank 5 — Users + Cleanup + All

Step 1 — Login: login.html → Email + Password → USERS page.
Step 2 — Add User: Users → Name + Email + Password + Role + Classes + Subjects → ADD USER → Firebase Auth + Realtime DB created.
Step 3 — Edit User: Users → EDIT → Change Classes / Subjects / Role → SAVE.
Step 4 — Reset Password: Users → RESET PASS → Sends reset email to user.
Step 5 — Delete User: Users → DELETE → Deletes DB profile — Then Firebase Console → Auth → Delete Auth user.
Step 6 — Cleanup: Cleanup → SCAN → Type DELETE → DELETE DEMO ONLY / DELETE ALL → Deletes demo data.
Rules: Admin sees ALL except Founder / Marketing / Financial / Employment — Those are Super Admin only. Admin cannot see Super Admin Dashboard.

👑 SUPER ADMIN — Rank 6 — All + Founder / Marketing / Financial / Employment

Step 1 — Login: login.html → Email + Password → SUPER ADMIN DASHBOARD.
Step 2 — Dashboard: Super Admin Dashboard → 4 tiles: Founder, Marketing, Financial, Employment → Tap to open in Manuals.
Step 3 — Print Full Pack: Manuals → PRINT → Save as PDF → Full 32 pages including 2,4,5,6.
Rules: Keep Super Admin login secret. Do NOT give to Principal / Admin / Staff. If leaked, change password in Firebase Console → Auth.

2. FOUNDER MANUAL — 👑 SUPER ADMIN ONLY — Rank 6

🔒 SUPER ADMIN ONLY. This section is hidden for Teacher / Librarian / HOD / Principal / Admin. It is only shown in Super Admin Dashboard + in Manuals when logged in as Super Admin. Do NOT share this section with staff.

Vision

Every book tracked. Every learner by ID. Every issue approved. No book lost. No learner without a book. One system for Grades 4-12, Classes 4A-12J, All Subjects.

Mission

Give every school in South Africa a simple, fast, offline-friendly LTSM system that works on a phone, with no training, with no paper, with barcode scanning.

Founder Story

Makhanani was built for Wordsworth High School first — To fix lost books, duplicate issues, and paper registers. It was then made to work for any school — Prefix from school name, Learner ID from grade + class, Subjects from CAPS. The founder is the Super Admin — The only person who can see Founder / Marketing / Financial / Employment.

School Setup — New School In 10 Minutes

1. Create school in Firebase — School ID (e.g. WHS) + School Name (e.g. WORDSWORTH HIGH SCHOOL) → Prefix auto = WHS.
2. Create Admin user in Users page — Role ADMIN — Rank 5.
3. Admin creates Teachers / Librarian / HOD / Principal in Users page.
4. Bulk Upload Learners + Books — CSV — See Section 9.
5. Print Barcodes — Barcode page — Stick on books.
6. Train staff — Section 3 — 10 minutes per role.
7. Go live — Teacher issues, HOD approves, Librarian tracks.

Legal / Registration

Keep school registration, SGB approval, and data consent in a file. Do NOT share learner names outside school. Do NOT share Financial / Employment sections outside Super Admin. Backup Firebase JSON monthly — See Section 8.

9. BULK UPLOAD — Learners + Books — CSV — All Roles

📥 Bulk Learners — NAME,GRADE,CLASS

Step 1: Make CSV in Excel / Google Sheets — Headers: NAME,GRADE,CLASS — One learner per row.
Step 2: Example:
NAME,GRADE,CLASS
THABO MOKOENA,10,10J
LERATO DUBE,10,10J
NALEDI SMITH,4,4J
Step 3: Go to Bulk Learners → Upload CSV → Check Preview → Upload → Learner IDs auto-created: 10J001, 10J002, 4J001.
Rules: Teacher: Own classes only — Others: Any class. Grade must match Class grade — e.g. Grade 10 + Class 10J — NOT Grade 10 + Class 4J. Name in CAPS. No commas in name.

📥 Bulk Books — SUBJECT,GRADE,QTY

Step 1: Make CSV — Headers: SUBJECT,GRADE,QTY — One subject per row.
Step 2: Example:
SUBJECT,GRADE,QTY
MATHEMATICS,10,30
ENGLISH HOME LANGUAGE,10,30
LIFE SCIENCES,10,30
Step 3: Go to Bulk Books → Upload CSV → Check Preview → Upload → Barcodes auto-created: WHS000001, WHS000002, etc.
Rules: Teacher: Own subjects only — Others: Any subject. Title auto = Subject + Grade — e.g. MATHEMATICS GRADE 10. QTY = Number of books — e.g. 30.

Common Errors

ErrorFix
⛔ MISMATCH — Class grade ≠ GradeChange Class to match Grade — e.g. Grade 10 → Class 10J
⛔ NO CLASSES — ASK ADMINAsk Admin to assign classes in Users page
⛔ Duplicate Learner IDCheck Learner ID already exists — Bulk will skip duplicate
⛔ CSV has commas in nameRemove commas — e.g. “MOKOENA, THABO” → “THABO MOKOENA”
