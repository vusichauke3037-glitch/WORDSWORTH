📖 3. TEACHER MANUAL — Teacher + HOD + Principal + Super Admin

3.1 Your Job

Teach your class. Add your learners. Add your books. Check My Retrieval % every week. Chase learners who did not return. Tell Librarian to follow up.

3.2 My Class Filter

Teacher Dashboard → My Class → Pick 4A → SAVE MY CLASS + SUBJECT → Everything filters to 4A only.
If you teach 4A + 5A, pick ALL MY CLASSES to see both together, or pick one at a time.

3.3 My Retrieval % — Teacher

Formula: My Retrieval % = (My Returned / My Issued) x 100
Example: You teach 4A. Librarian issued 10 books to 4A. 8 returned. My Retrieval % = 80% — Red — You must chase 2 learners.
Steps: 1. Open Teacher → My Retrieval % → Still Out List → See 2 learners → Tell them: Bring book tomorrow → Tell Librarian.
2. When they return, Librarian marks RETURNED → Your Retrieval % goes to 90% → 100%.

3.4 Add Learner / Add Book

Teacher → My Learners → Learner ID + Name + Class → ADD LEARNER.
Teacher → My Books → Book ID + Title + Subject + Class → ADD BOOK.
Learner ID must be unique. Book ID / Barcode must be unique. Use CAPS.

3.5 Teacher Cannot Issue / Return

Only Librarian can Issue / Return. Teacher can see My Issues (Read Only). If a learner gives you a book, give it to Librarian — Librarian marks RETURNED — Your Retrieval % updates.

3.6 Subscriptions — Teacher

Teacher sees My Subscription (Read Only). Teacher cannot change package. To upgrade, tap REQUEST UPGRADE → WhatsApp 078 023 3263 → Super Admin changes it.

📚 7. LIBRARIAN MANUAL — Librarian + Principal + Super Admin

7.1 Your Job

You are the only person who can Issue / Return / Mark Lost. If you do not mark RETURNED, Retrieval % stays low and Principal will chase you. Mark RETURNED the same day the book comes back.

7.2 Issue Book — Step By Step

1. Librarian → Issue Book → Learner ID (e.g. L001) → FIND LEARNER → Name + Class auto-fill.
2. Book ID / Barcode (e.g. BK001) → FIND BOOK → Title auto-fill.
3. Tap 📕 ISSUE BOOK → ✅ Issued.
4. KPI: Issued +1 — Retrieval % drops until returned.

7.3 Return Book — Step By Step

1. Librarian → Return Book → Issue ID OR Learner ID + Book ID → ✅ RETURN BOOK.
2. Or: Issues Table → Filter Still Out → Tap ✅ RETURN on that row.
3. Or: Retrieval Card → Still Out List → Tap ✅ RETURN.
4. KPI: Returned +1 — Retrieval % goes up.

7.4 Mark Lost

If learner says book is lost / damaged: Librarian → Return → Issue ID → ❌ MARK LOST → Confirm.
Lost books count as NOT returned — Retrieval % drops — Principal sees Lost count. Do NOT mark LOST unless you are sure.

7.5 Retrieval % — Librarian

Formula: Retrieval % = (Returned / Issued) x 100
Every Friday: 1. Open Librarian → Retrieval % → Still Out List Top 20.
2. Print / Screenshot Still Out List → Give to Teachers + Principal.
3. Monday: Check again — Did Retrieval % go up? If not, chase again.

7.6 Stock + Barcode

Librarian → Stock → Book ID + Title + Subject + Grade + Qty → ADD STOCK.
Barcode: Use phone camera / scanner to scan Book ID into Book ID field, then FIND BOOK.

7.7 Subscriptions — Librarian

Librarian sees My Subscription (Read Only). Cannot change package. To upgrade, tap REQUEST → WhatsApp 078 023 3263.
