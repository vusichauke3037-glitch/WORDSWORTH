🚀 Start Here — How Makhanani Works (4 Steps)

1. TEACHER requests books → 2. HOD approves MAX → 3. LIBRARIAN issues up to MAX to learners → 4. PRINCIPAL sees report.
Golden Rule: APPROVE = SET MAX. Librarian can NEVER issue more than HOD approved MAX.
Login: Go to login.html → Type email + password → You go straight to your role dashboard.
No account? Ask Principal / Super Admin to create it in Super Admin → Users.
Due Date: All books due 30 November every year. Overdue = after 30 Nov.

👩‍🏫 TEACHER Manual

  1. Login → You land on Teacher page.
  2. Go to 👤 MY PROFILE → Tick ALL Grades + Subjects + Classes you teach → 💾 SAVE MY PROFILE.
  3. Go to 📚 MY REQUESTS → Pick Book → Subject → Grade → Class → Qty → SEND REQUEST TO HOD.
  4. Wait for HOD to approve. Status changes: PENDING → APPROVED → ISSUED.
  5. Check 📦 ISSUED to see what Librarian gave you.
  6. Check 🧑‍🎓 LEARNERS to see who has a book / who has no book.
  7. 🖨️ REPORT → OPEN REPORT → PRINT / PDF for HOD / Principal.
Do NOT: Issue books yourself. Only Librarian issues. Only HOD approves.

👑 HOD Manual — APPROVE = SET MAX

  1. Login → HOD page.
  2. Go to 👤 MY PROFILE → Tick ALL Grades + Subjects you oversee. Example Mrs Nkambule: Grades 10, 11, 12 + ACCOUNTING + Classes 10A, 11A, 12A → Save.
  3. Go to ⏳ APPROVE → You see all Teacher requests for your subjects/grades.
  4. For each request: Type Approve MAX — e.g. Teacher asked 50, you type 30 → Librarian can issue MAX 30.
  5. Tap ✅ APPROVE → Goes to Librarian. Or ❌ REJECT with reason.
  6. Go to ✅ DECIDED → See what you approved / rejected → Tap 🔄 CHANGE MAX to change MAX later.
  7. 🧑‍🎓 LEARNERS → See who has book / no book / overdue.
  8. 🖨️ REPORT → For Principal / SGB.
Example: Teacher asks 50 Accounting Grade 10 books. Stock is 35. You approve MAX 30. Librarian issues 30. 20 learners wait — Cut = 20.

📖 LIBRARIAN Manual

  1. Login → Librarian page.
  2. Go to ✅ APPROVED → These are HOD-approved requests. Never issue more than MAX.
  3. Tap 📦 MARK ISSUED when you give books to Teacher.
  4. Go to 📦 ISSUE TO LEARNER → Type Learner ID + Book No (barcode) + Title + Grade + Class → ISSUE BOOK. Due = 30 Nov.
  5. To return: Type Book No in ↩️ RETURN BOOK → RETURN.
  6. 🧑‍🎓 LEARNERS → Add learner, see who has what, return books.
  7. 📚 BOOKS → Add book, adjust stock with 📦 +/- STOCK.
Never: Issue a book that HOD did not approve. Never issue more than MAX.

🏫 PRINCIPAL Manual

  1. Login → Principal page — you see YOUR school only.
  2. 👥 USERS → See all staff in your school. Tap ✏️ EDIT to fix a Teacher/HOD Grades / Subjects / Classes (prompts).
  3. 📚 REQUESTS → View only — you do NOT approve. HOD approves.
  4. 💳 SUBSCRIPTION → See your plan, expiry, days left. Tap VIEW PLANS / UPGRADE to upgrade.
  5. 🖨️ REPORT → OPEN REPORT → PRINT / PDF for SGB / District.
  6. 👤 MY PROFILE → Tick Grades/Subjects only if you also teach.

👑 SUPER ADMIN Manual — Xintimani Group

  1. Login → Super Admin page — you see ALL schools.
  2. 👥 USERS → Add / Edit user. Tick MANY Grades + Subjects + Classes. Tap ✏️ EDIT to change Role (TEACHER → HOD) + Grades + Subjects + Classes in one save.
  3. 🏫 SCHOOLS → Add school.
  4. 💳 SUBSCRIPTIONS → Add / Extend subscription. Plans: DEMO, STARTER, STANDARD, PREMIUM.
  5. 📚 BOOKS → Add book for any school.
  6. 🖨️ REPORT → All schools report.
  7. ⚙️ SYSTEM → Version + links.
Fix Mrs Nkambule example: Users → Find MRS NKAMBULE → ✏️ EDIT → Role = HOD, Tick GRADE 10, 11, 12 + ACCOUNTING + 10A, 11A, 12A → SAVE CHANGES.

👤 MY PROFILE — Multi-Select Grades / Subjects / Classes

Every role has MY PROFILE. You can edit your own Grades / Subjects / Classes without asking Super Admin.
You CAN change: Name, Grades, Subjects, Classes.
You CANNOT change: Role, Email, School — only Super Admin can change Role.
  1. Go to your dashboard → 👤 MY PROFILE tab.
  2. Tick ALL Grades you teach / oversee — e.g. GRADE 10, 11, 12.
  3. Tick ALL Subjects — e.g. ACCOUNTING + BUSINESS STUDIES.
  4. Tick ALL Classes — e.g. 10A, 10B, 11A, 12A. Use SELECT ALL / CLEAR to go fast.
  5. If subject/class missing: Type it in ➕ Add other → ADD.
  6. Tap 💾 SAVE MY PROFILE → Confirm → Done. Reload shows new values.
If you tick NOTHING: You will see 0 requests / 0 learners. Tick at least 1 Grade + 1 Subject.
