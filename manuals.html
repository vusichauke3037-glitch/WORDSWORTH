🚀 Quick Start — 5 Minutes — Read This First

Step 1 — Login: Open login.html → Enter Email + Temp Password from School Admin → Login → You land on index.html (Home).
Step 2 — Check Your Role: Top shows your Role + School. e.g. LIBRARIAN • Makhanani Primary. Menu changes by role.
Step 3 — Flow (The Whole System In 4 Steps):
1. Teacher Requests Books (Teacher page) → 2. HOD Approves + Sets MAX (HOD page) → 3. Librarian Issues to Teacher up to MAX (Librarian page) → 4. Teacher Issues to Learners OR Librarian Issues Direct to Learner → 5. Librarian Collects Returns.

📚 Librarian — librarian.html V1 — READ THIS IF YOU ARE LIBRARIAN

Librarian is the heart of LTSM. You issue to Teachers, issue direct to Learners, collect Returns, re-print barcodes, and print receipts. You do NOT approve requests (HOD does) and you do NOT set MAX (HOD does).

Daily Flow — Morning

1. Open Librarian page: librarian.html → See Dashboard: Issued / To Teachers / To Learners / Returned / Book Titles / Total Copies / Available / Pending Approvals.
2. Check Approved Requests: Top section ✅ Approved Requests — Ready To Issue shows e.g. Madlala — Grade 5 5A — English — MPS000001 — Requested 30 • MAX 30 • Already Issued 0 • Remaining 30. If empty, no HOD approvals yet — Tell Teachers to request, HOD to approve.
3. Issue To Teacher: Click 📦 ISSUE TO THIS TEACHER → Fills Approved Request → Enter Qty (e.g. 30) → Press ISSUE TO TEACHER. System checks: Qty ≤ Remaining MAX? If you try 31 when MAX 30, system blocks: MAX EXCEEDED. System also checks Stock: Held + Qty ≤ Total? If not enough books, system blocks: NOT ENOUGH STOCK.
4. Teacher Signs: After issue, find issue in list → Press 🖨️ PRINT RECEIPT → Teacher signs → Keep in Library File. Receipt shows Learner ID / Teacher, Book No, Date, Conditions, 4 Signature lines.

Scan Issue To Learner — Fast Lane (2 Seconds)

1. In 📷 SCAN TO ISSUE, click Learner field → Scan learner barcode (or type 5A001 + Enter) → Shows ✅ Learner: Thandi Mokoena — 5A001 • Grade 5 5A → Focus moves to Book field.
2. Scan book barcode (or type MPS000001 + Enter) → Shows ✅ Book: English Grade 5 — MPS000001.
3. Press SCAN ISSUE TO LEARNER → Done. Fields clear, ready for next learner. Scan next learner immediately.
Blocks: If learner already has that exact Book No, system blocks: ALREADY HAS. If no stock, system blocks: NOT ENOUGH STOCK.

Manual Issue To Learner (No Scanner)

Re-Print Barcode (Sticker Lost / Torn)

Print Records

❓ FAQ

Q: Can one learner have same Book No as another learner?
A: No. One Book No = One physical book. One learner at a time. When returned, it can go to next learner.

Q: Can two schools have same Book No?
A: Yes, but with different school prefix. e.g. Makhanani = MPS000001, Bushbuckridge Primary = BPS000001. Per school, never duplicate.

Q: Can Librarian approve?
A: No. Only HOD / Principal / School Admin approve. Librarian issues from approved requests only.

Q: Can Teacher issue books they do not hold?
A: No. System blocks. Librarian must issue to Teacher first.

Q: What if learner loses book?
A: Librarian → Return → Condition = Lost → Note → School Admin / Principal follows up with parent for replacement charge.

Q: What if sticker torn?
A: Librarian → Re-Print Barcode → Same ID, same barcode.

Q: How much per school?
A: R 15,000 per school per year (example in Projections — Edit to your price). Due: 30 Nov Every Year.

Q: Does it work offline?
A: No, needs internet (Firebase). Works on phone data / WiFi. Data is live.
