👩‍🎓 Upload Learners — CSV

Learner CSV Format: Name, Grade, Class — 1 learner per line
Example: Thabo Chauke, 10, A → Auto ID 10A001
OR with ID: Thabo Chauke, 10, A, 10A001 — If ID is blank, system auto-fills next ID in that class.

👩‍🏫 Upload Teachers — CSV

Teacher CSV Format: Name, Email, Password, Role — 1 teacher per line
Example: Thabo Chauke, teacher@school.co.za, 1234, Teacher
Roles: Teacher, Librarian, Principal, Admin, Super Admin
If Role is blank → Teacher. If Password is blank → 1234.

⚡ Upload Rules

  • Learners: Name, Grade, Class — Grade 10, Class A → ID 10A001 auto. If you give ID, system uses it. If ID already exists, choose Skip / Overwrite / New ID.
  • Teachers: Name, Email, Password, Role — Email must be unique per school. Password blank = 1234. Role blank = Teacher.
  • Max: 500 rows at once. If more, split into 2 uploads.
  • Header row: If first row is Name, Grade, Class or Name, Email..., system auto-skips it.
  • After Import: Learners appear in learners.html + teacher.html (My Class). Teachers appear in add_school.html + super_admin.html → Can login in index.html.
