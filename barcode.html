📱 How To Scan + Stick — Learner + Book

  1. Print: 15 labels = 1 A4 page. Cut along dashed lines. Green border = LEARNER, Blue border = BOOK.
  2. Learner: Stick green label on learner card / file. Cover with clear tape.
  3. Book: Stick blue label inside front cover, top right. Cover with clear tape.
  4. Issue: Home → Search → Scan learner `10A001` → Learner opens → Click Issue → Scan book `BK001` → Done.
  5. Return: Same — Scan learner → Click Return → Scan book.
  6. No scanner? Type code manually: `10A001` or `BK001` in Home Search → Press Enter.

⚡ Quick Rules

  • 1 learner = 1 code. 1 copy = 1 code. Never reuse.
  • Green = Learner, Blue = Book. Don't mix them when sticking.
  • Lost label? Same name + Same code → Print again. Do NOT make new code.
  • Print test first: 1 page on plain paper, scan 1 barcode with phone camera.
