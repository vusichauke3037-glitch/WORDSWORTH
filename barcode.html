📱 Scan Test — Must Scan With Phone Camera

  1. Print 1 page on plain paper first.
  2. Open phone camera → Point at barcode below → Must show code.
  3. If it does NOT scan: Check Print Settings — Margins None, Scale 100, Background ON, Headers OFF. Do NOT shrink.
  4. Cut along dashed lines. Stick learner inside card, textbook inside front cover. Cover with clear tape.

⚡ Quick Rules — Scannable

  • 1 learner = 1 Learner ID. 1 textbook copy = 1 Textbook Number. Never reuse.
  • Lost label? Same name + Same number → Print again. Do NOT make new number.
  • Print test first: 1 page plain paper, scan 1 barcode with phone camera. Must show code.
  • Do NOT photocopy barcodes smaller — They will not scan. Print at Scale 100, A4, Margins None.
