⚡ Quick Rules — Learner

  • Learner ID = Grade + Class + 3 Digits. Example: Grade 10, Class A, 1st learner = 10A001.
  • 1 learner = 1 ID. Never reuse.
  • Lost card? Same name + Same ID → Print again. Do NOT make new ID.
  • Print test first: 1 page plain paper, scan 1 barcode with phone camera. Must show ID.
  • Do NOT photocopy smaller — Will not scan. Print Scale 100, A4, Margins None.
