➕ 1 Learner Barcode — For New Learner / Lost Card

Code rule: Prefix (from your school) + 3-digit number. Example: School Prefix 10A + 001 = 10A001. Do NOT reuse a code — Each learner must have unique code.

📋 All Learners — Search + Print 1 By 1

📱 How To Scan Learner Barcode

  1. Print labels from this page — 15 per A4 page, cut along dashed lines.
  2. Stick 1 label on learner card / learner file / exercise book.
  3. Teacher opens `home.html` → Search box at top.
  4. Scan barcode with phone camera / barcode scanner — Code `10A001` types itself into Search box.
  5. Learner opens → Click Issue Book → Scan book barcode → Done in 10 seconds.
  6. Return: Same — Scan learner → Click Return → Scan book.
No scanner? Type code manually: In Home Search, type `10A001` → Press Enter → Learner opens. Scanner just types faster.

⚡ Quick Rules

  • 1 learner = 1 code. Never give 2 learners same code — System will mix up their books.
  • Lost card? Use Tab 1 Learner → Same name + Same code → Print again. Do NOT make new code.
  • New learner? Use next number — If last learner is 10A015, new learner is 10A016.
  • Print test first: Print 1 page on plain paper, scan 1 barcode with phone camera — Must show code. Then print on sticker paper.
