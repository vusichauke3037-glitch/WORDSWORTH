🖨️ Barcode Print — 3 x 5 on A4 (15 per page)

School: —
How to print:
1. Pick 🎓 Learners or 📖 Textbooks below → Filter by Grade / Subject → Tick the ones you want
2. Tap 👁️ Preview 3x5 A4 → Check labels look right
3. Tap 🖨️ Print A4 → In print dialog: Paper = A4, Margins = None, Scale = 100%, Background graphics = ON
4. Print on plain A4 → Cut on dotted lines → Stick on books / learner cards

Paper: Plain A4 works. For books, use sticker paper / clear tape over barcode so it doesn’t peel.

✅ Tick What To Print — 0 selected • 0 page(s) A4

Tick boxes below. 15 labels = 1 A4 page. 30 labels = 2 pages, etc. Untick ones you already printed.

✅ Printed?

If barcodes scanned OK in issue.html / librarian.html, you’re done. If a barcode won’t scan, reprint that one — check printer ink / paper not glossy / barcode not cut off.
