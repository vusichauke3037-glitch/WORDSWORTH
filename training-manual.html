3. Module 1 — Login (10 min) — Email + Password

Say this: "Login changed. No more PIN. Now you use 3 things: School, Email, Password."

Demo On Your Phone (2 min)

  1. Open index.html → Show School Dropdown
  2. Click Dropdown → Pick school, e.g. WORDSWORTH PRIMARY → Show School Info appears
  3. Type Email: principal@wordsworth.co.za
  4. Type Password: 1234 → Click 👁️ to show/hide
  5. Click LOGIN → Principal Dashboard opens
Example Logins — Use on Training Day:
School: WORDSWORTH PRIMARY (Dropdown)
Principal: principal@wordsworth.co.za / 1234
Librarian: librarian@wordsworth.co.za / 1234
Teacher: teacher@wordsworth.co.za / 1234

Replace with real school + real emails on training day.

Make Them Do It (8 min)

  1. Each person opens link on their own phone
  2. Each person picks School from Dropdown
  3. Each person types their Email + Password
  4. Each person clicks LOGIN
  5. If Forgot Password: Click Forgot Password? → WhatsApp Vusi → Reset to 1234 → Login with 1234
Common Mistakes to Fix On Spot:
• Picking wrong school — Check Dropdown first
• Typing email with space at end — Delete space
• Caps Lock on — Password is case-sensitive: School2026 ≠ school2026
• Using old PIN as password — Old PIN IS now password, same number works

4. Module 2 — Librarian (20 min) — Add Learners + Books

A. Add 3 Learners — 1 By 1 (5 min)

  1. Librarian opens librarian.html
  2. Go to Learners → Name, Learner ID, Class → Add Learner
  3. Use 3 REAL learners from that school, e.g. Thandi Mokoena | L001 | 10A
  4. Show Search: Type Tha → Thandi appears

B. Bulk Upload Learners (5 min)

Say: "If you have 100 learners, do not add 1 by 1. Use Bulk."

Paste This Format — Must Use | Exactly:
Thandi Mokoena | L001 | 10A | 10 | 0780233263
Sipho Dube | L002 | 10A | 10 | 0781112222
Lerato Nkosi | L003 | 10B | 10 | 0782223333

Format: Name | Learner ID | Class | Grade | Parent Phone
  1. Librarian opens Bulk Upload → Paste 3 lines above → Upload
  2. Show: 3 learners added

C. Add 3 Books (5 min)

  1. Go to Textbooks → Title, Barcode, Subject, Grade → Add Textbook
  2. Use 3 REAL books, e.g. Mathematics Grade 10 | BK001 | Mathematics | 10

D. Bulk Upload Books (5 min)

Paste This Format:
Mathematics Grade 10 | BK001 | Mathematics | 10 | Maskew Miller
English Grade 10 | BK002 | English | 10 | Oxford

Format: Title | Barcode | Subject | Grade | Author
Barcode Rule: Barcode must be unique. If you add BK001 twice, second overwrites first. Use BK001, BK002, BK003...

E. Add 1 Teacher (2 min)

  1. Go to Teachers → Name, Email, Password, Subject, Class → Add Teacher
  2. Example: Mr. Nkosi | teacher@school.co.za | Nkosi2026 | Mathematics | 10A
  3. Tell Teacher: "Login with School Dropdown → Your Email → Your Password"

5. Module 3 — Issue / Return (15 min) — Practice

A. Issue (7 min)

  1. Everyone opens issue.html
  2. Type learner: Tha → Click Thandi Mokoena
  3. Type book: Mat → Click Mathematics Grade 10
  4. Click ISSUE BOOK → Show: Success, Due Date = 14 days
  5. Show Books Out Now: Thandi has Mathematics

B. Return (5 min)

  1. Go to Return Book tab → Search Thandi → Click Return Now
  2. Show: Book is Available again

C. Overdue + WhatsApp Parent (3 min)

  1. Go to Overdue tab → Show red list (if any)
  2. Click WhatsApp Parent → WhatsApp opens with pre-filled message → Send
Issue Rules to Say Out Loud:
• 1 book = 1 issue. 3 books = Issue 3 times.
• Due date = Automatic 14 days.
• If book is already OUT, do not issue same barcode twice.
• If learner has no phone, add parent phone in Librarian → Learners to WhatsApp parent.

6. Module 4 — Principal + Teacher (10 min)

Principal (5 min)

  1. Principal opens principal.html → Show KPIs: Learners, Books, Out, Overdue
  2. Go to Overdue → Click WhatsApp Parent → Send
  3. Go to Books Out → Search learner
  4. Go to Finance → Show Package, Monthly, Renew button
Principal Rule: Principal cannot edit learners / books. Librarian does that. Principal views + acts on overdue.

Teacher (5 min)

  1. Teacher opens teachers.html → Show: My Class Only, e.g. 10A
  2. Go to My Learners → Search
  3. Go to Overdue — My Class → WhatsApp Parent
If Teacher sees blank: Class not set. Librarian must add Teacher with Class = e.g. 10A and Email = login email. Fix on spot.

7. Module 5 — Profile — Change Password (5 min)

Do this last — So they leave with their own password.

  1. Everyone opens profile.html
  2. Show My Info: Name, Email, School, Role, Class, Package
  3. Go to Change My Password:
  4. Old Password: 1234
  5. New Password: e.g. Thandi2026 (Min 6, letters + numbers)
  6. Confirm New Password: Thandi2026 (Must match)
  7. Click Change Password → Green: Password Changed!
  8. Logout → Login again with New Password to prove it works
Say This:
"Do NOT share your password with learners. Do NOT use 123456 or your phone number. If you forget, WhatsApp Vusi, he resets to 1234, then you change it here again."
Password Rules to Write on Board:
Min 6 characters • Letters + Numbers • Example: School2026 • Must know Old Password to change
