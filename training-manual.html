❓ Training Q&A — What Librarians Ask

QuestionAnswer
"What if I issue wrong book?"Go to Return tab → Return it → Issue correct book. Takes 5 seconds.
"What if learner loses book?"Book stays OUT. Principal sees it in Overdue. WhatsApp parent.
"What if internet is off?"Wait for data. System needs internet. Use phone data, not school WiFi if WiFi is slow.
"Can I use my own phone?"Yes. Any phone. Login with school + email + PIN.
"Will learners see my PIN?"No. Never share PIN. Change PIN in Profile if someone sees it.
