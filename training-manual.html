Trainer Script — What To Say

Opening (2 min): “Makhanani LTSM helps you know WHERE every book is, WHO has it, and WHEN it must come back. No more lost books. No more paper registers.”
Golden Rule: “1 Subject per Learner. System checks it for you. You don't need to remember.”
Barcode Rule: “Always scan BOTH barcodes — Learner + Book. Never issue without scanning.”
Slip Rule: “No slip = No proof. Always print slip and get signature.”

Hands-On Exercises — Do These In Training

Exercise 1 — Learner: Add learner: Thabo Nkosi, Grade 10, 10A → Find his barcode → Print sticker.
Exercise 2 — Book: Add book: Platinum Accounting, ACC, Grade 10, Qty 1 → Find barcode → Print sticker.
Exercise 3 — Issue: Issue Thabo + Accounting book → Print Slip → Check Due Date.
Exercise 4 — Block Test: Try to issue Thabo a 2nd Accounting book → Must show BLOCKED. Explain why.
Exercise 5 — Return: Return the book as Good → Book becomes Available → Issue again to prove it works.
Exercise 6 — Damaged: Mark book Damaged → Try to issue it → Must NOT issue. Mark Good → Issue works again.

Common Mistakes To Train Out

❌ Selecting wrong EMIS → Show Switch School. ❌ Typing barcode with O instead of 0 → Show copy/paste. ❌ Issuing without checking name on screen → Always check. ❌ Forgetting to print slip → Always print. ❌ Deleting learner/book that is OUT → Return first. ❌ Sharing password → Each person own account.

Assessment — Pass / Fail (5 Questions)

1. How do you select your school? (Answer: By EMIS) 2. What is 1 Subject per Learner? 3. What 2 barcodes do you scan to issue? 4. What do you do if book is Damaged? 5. How do you print stickers? (Answer: 3x5 A4, 15 per page).
Pass: 4/5 + Can do 1 Issue + 1 Return alone without help.

✅ After Training Checklist: ☐ All staff can login alone ☐ 1 page stickers printed ☐ Each person did 1 Issue + 1 Return ☐ Principal can Add Staff + Approve ☐ Guides printed: Principal (1), Librarian (2), Learner (per learner) ☐ School knows support number.
Trainer Note: Leave school with: ZIP v1.87 + 3 Guides + Support number. Call school after 3 days: “How many books issued? Any stuck?” If 0 issued, offer free 15-min follow-up call.
